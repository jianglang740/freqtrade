# 落地策略：XsecMomentum

> 研究到此为止。这份文档只做一件事：把 01–05 得出的规则，变成一个能跑、能回测、
> 能上 dry-run 的 freqtrade 策略，并把「研究口径」和「落地口径」的差异逐条交代清楚。
>
> 策略文件 [`user_data/strategies/XsecMomentum.py`](../../user_data/strategies/XsecMomentum.py)，
> 配置 [`user_data/config/config_xsec.json`](../../user_data/config/config_xsec.json)。
> 生成日期 2026-11-04。

## 结论速览

1. **策略已经能跑**：2023-01-01 → 2026-10-30、币安 U 本位 95 个永续、fee 3bp，
   **年化 30.92% / 日净值波动 26.3% / Sharpe 1.13 / 最大回撤 22.95%**。
2. **但这个数字不能当收益预期。** 白名单是**今天还活着的** 95 个永续，已下架的一个都看不见。
   预期请用报告 04/05 的 2023+ 口径：**13–16% 年化、Sharpe 0.6–0.7、回撤 −35%**。
3. **两个硬约束没有变**：容量 **$1–5M**；必须用合约（现货做不了空腿）。
4. **前视已经用区间截断法验过**：把回测截到 2024-06，重叠期内 1091 笔已平仓交易
   逐笔完全一致，净利润差 **0.000000 USDT**。

## 一、策略到底在做什么

| 环节 | 规则                                                                               | 出处            |
| ---- | ---------------------------------------------------------------------------------- | --------------- |
| 选池 | ADV(14 日) ≥ $1M → 剔除稳定币/法币 → 28 日年化波动率 ≥ 15% → 按 ADV 取前 50   | 05 §三 Stage A |
| 打分 | 7/14/28 日「动量 ÷ 同窗口收益波动」，三窗口等权平均，**只在池内**做截面排名 | 01 §1.3        |
| 建仓 | 池内前 20% 做多、后 20% 做空，每腿等权（50 个池 ≈ 每腿 10 个）                    | 01 §1.4        |
| 调仓 | 日频。排名掉出分位就平仓 —— **这就是调仓本身**，不是止损                   | 03 §二         |
| 仓位 | O2：`k = 0.20 / 63 日已实现年化波动`，用 t-1 的信息，乘到每笔 stake 上           | 04 §六         |
| 止损 | 无。只有一个 −25% 的兜底 `stoploss`                                             | 03 §五         |

没有加任何东西：没有持有缓冲（03 实测是负贡献）、没有单币止损（越紧越坏）、
没有挤空过滤（在诚实池上失效）、没有 ROI（`minimal_roi` 设成 1000% 等于关掉）。

## 二、和研究口径的差异（逐条，不藏）

| # | 研究口径                           | 落地口径                                   | 影响                                          |
| - | ---------------------------------- | ------------------------------------------ | --------------------------------------------- |
| 1 | 704 币现货面板，含 199 个已下架    | 95 个**当前在交易**的永续            | **最大的一条**。收益率被幸存者偏差抬高  |
| 2 | 池 50 / 候选约 200 = 前 25%        | 池 50 / 候选 95 = **前 53%**，更宽松 | 研究里放宽池子是坏方向（B1/B2），这里是被迫的 |
| 3 | O2 上限 2.0×                      | **上限 1.0×**                       | 平静期少赚，风险也同比更低                    |
| 4 | 每日把权重**重新配平**到等权 | 只在进出时成交，持有期内权重自然漂移       | 换手略低；权重有漂移                          |
| 5 | 收盘到收盘收益                     | 次日开盘成交                               | 差异落在隔夜跳空里，不可消除                  |
| 6 | 无止损                             | −25% 兜底                                 | 4687 笔里触发 **137 次（2.9%）**        |
| 7 | 现货面板                           | 期货永续（资金费由框架自动结算）           | 数据里已有 1h 资金费，已计入                  |

第 2 条我实测了两种映射，**不挑好看的那个说**：

| 映射                            |     每腿个数 |             CAGR |         Sharpe |         最大回撤 |
| ------------------------------- | -----------: | ---------------: | -------------: | ---------------: |
| 池 25（选择性对齐 26%）         |            5 |            9.63% |           0.43 |           33.85% |
| **池 50（结构对齐研究）** | **10** | **30.92%** | **1.13** | **22.95%** |

最终取 50，理由不是它数字好，而是它精确复现了研究里**唯一被验证过的结构参数
「每腿 10 个」**（01/02 的 V5、04 的主口径、05 的 B0 全是 10 个）。
「池 25 会更接近研究的 25% 选择性」这个说法今天站不住 —— 数据给出了相反的答案。
**这一条是已知的口径妥协，写在这里。**

## 三、回测结果

`--timerange 20230101-20261030 --fee 0.0003`，币安 U 本位，`max_open_trades = 20`：

| 指标               |   数值 |
| ------------------ | -----: |
| 年化（CAGR）       | 30.92% |
| 年化波动（日净值） |  26.3% |
| Sharpe（日净值）   |   1.13 |
| 最大回撤           | 22.95% |
| 交易笔数           |   4687 |
| 胜率               |  42.0% |
| Profit factor      |   1.13 |
| 平均持仓           | 4.7 天 |

分年（按年初账户权益起算，含年末浮盈）：**2023 +22.02% / 2024 +90.76% / 2025 +31.52% / 2026 −10.31%**

多空拆解：

| 腿 | 笔数 | 单笔均值 | profit_ratio 之和 |
| -- | ---: | -------: | ----------------: |
| 多 | 2092 |   +1.23% |  **+25.68** |
| 空 | 2595 |  −0.01% |  **−0.36** |

**空腿的贡献是零。** 它在这三年里既没赚也没赔 —— 和研究里「空腿不是 alpha 来源，
是一个每年花 20% 买来的 beta 对冲」完全一致。区别只是这三年标的没怎么跌，
所以对冲成本由多头覆盖了。**如果下一个周期是多头普涨，空腿会把利润吃回去。**

### 为什么这个数字比报告里的 15.6% 高

不是策略变好了，是**币池换了**：95 个当前活着的永续，比 704 个含死币的现货池
更「优质」。报告 04 已经量过，生存者偏差对**回撤**的影响是稳定的 ~20pp，
对收益的影响不稳定。在这个 3.8 年的短样本上，它同时抬高了收益。
**所以：回测数字用来确认「策略能跑通、行为符合预期」，不是收益预期。**

## 四、前视自查

`freqtrade lookahead-analysis` **对横截面策略必误报**（它只加载单个 pair，
看不到其他币的排名），所以不用它。改用区间截断法：

```
跑 2023-01-01 → 2026-10-30，记录 2024-05-01 前的已平仓交易
跑 2023-01-01 → 2024-06-01，同样记录
```

结果：**1091 笔交易逐笔完全一致，净利润差 0.000000 USDT**。

如果面板构造偷看了未来（比如回测时 `get_pair_dataframe` 拿到了超出当天的数据），
两次跑出来的重叠期一定不同。一致说明面板只做了「按日期对齐 + 逐行排名」，
没有用任何 t 之后的数值。

> 长区间在 2024-06-01 的余额是 13867.00、短区间末值是 13881.07，差 0.10%。
> 这是**未平仓头寸按市值估值**与「只结算已平仓」的口径差，不是前视。

## 五、怎么跑

```bash
source /opt/anaconda3/etc/profile.d/conda.sh && conda activate freqtrade

# 回测（研究报告口径，3bp）
freqtrade backtesting -s XsecMomentum -c user_data/config/config_xsec.json \
  -i 1d --timerange 20230101-20261030 --fee 0.0003 --export trades

# 真实费率口径（币安 U 本位 taker 0.05%）
freqtrade backtesting -s XsecMomentum -c user_data/config/config_xsec.json \
  -i 1d --timerange 20230101-20261030 --fee 0.0005

# dry-run（端口 8084，独立数据库 tradesv3.xsec.sqlite）
freqtrade trade -s XsecMomentum -c user_data/config/config_xsec.json
```

**不要动** 8080（网格）和 8082（海龟）两个正在跑的实例的配置。

数据前提：`user_data/data/binance/futures/*-1d-futures.feather` 和
`*-1h-funding_rate.feather`，共 95 个永续。要加币就 download-data，
**之后必须重跑 `python gen_data_report.py`**，并把 `config_xsec.json` 的
`pair_whitelist` 和 `max_open_trades` 一起改（`2 × round(TOP_N × Q)`）。

## 六、上线前还必须做、而这份代码没做的事

1. **容量没验。** 回测假设可以无限吃单。按报告 05 的平方根模型，$1M 能装、
   $10M 装不下。**先想清楚这笔钱多大再来谈策略。**
2. **空腿做空的可交易性没验。** 资金费是框架自动扣的，但借币/保证金/强平
   这些只有实盘才知道。尤其是小币永续的深度，回测里是免费给的。
3. **没做 dry-run。** 只跑了回测。`custom_stake_amount` 在实盘里拿的是
   `self.wallets.get_total_stake_amount()`，账户里还有别的策略在跑时会互相干扰 ——
   **必须单独一个账户/子账户**。
4. **每日只在一个时点调仓。** 实盘的开盘价和回测的开盘价不是一回事，
   滑点在 1d 尺度上很小但存在。
5. **币池会漂。** 今天前 50 的 ADV 排名，三个月后不是这个名单。
   策略每天自己重算，不需要人工干预，但**新增的币会因为历史太短被排除在池外**，
   这是刻意的。

## 七、这策略不适合谁

- **资金超过 $5M 的，不适合。** 冲击成本会吃掉全部超额。
- **受不了 −35% 回撤的，不适合。** 报告 04 的 −56% 是真实发生过的形态，
  这一版靠 O2 和 1× 上限压到了 −23%（回测），但没有理由认为长期能保持。
- **想要「稳定每月正收益」的，不适合。** 2024 年只有 +0.3%（诚实池）、
  2026 年 −10.31%，连续一年不赚钱是已经发生过的事。
- **只能做现货的，不适合。** 空腿是这个结构的一半，去掉就变成另一个策略，
  而那个策略没有验证过。
