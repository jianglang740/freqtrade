# 01 原始设想：15 日区间突破（AlphaPilot 版）

> 来源：AlphaPilot 策略页《15 日区间突破：做多高位、做空低位》
> <https://www.alphapilot.tech/zh-CN/playbooks/15-day-range-breakout-long-crypto-highs-short-the-lows-133-ff2642>
> 抓取时间 2026-11-09。下面「原文口径」一节是页面自述，未经我方验证。

## 1. 原文口径

| 项目 | 原文设定 |
|---|---|
| 因子 | `breakout = (close − min(close, 90)) / (max(close, 90) − min(close, 90))` |
| K 线 | 4h，90 根 = 15 天；min/max **用 close**，**含当前 bar** |
| 含义 | 1 = 15 日收盘区间顶，0 = 区间底 |
| 标的池 | AlphaPilot 自述的 "head" 加密池，USDT 永续 |
| 样本 | 2025-04-01 → 2026-10-31（19 个月） |
| 调仓 | 每周一 UTC 00:00；有效币 < 10 个则跳过 |
| 组合 | 前 20% 做多、后 20% 做空，腿内等权，两侧各占 50% 资金，1× 杠杆 |
| 成本 | 摩擦 0.03%（单边），计入资金费 |
| 自述结果 | 收益 +133.13%，年化 +70.51%，Sharpe 2.08，MaxDD 18.82%，1,562 笔，手续费 5.1%，资金费 6.3%，同期基准 −46.2% |
| 自述逻辑 | 强势延续（动量）+ 市场中性；多腿 49.4%、空腿 −48.5% 平均暴露 |
| 自述改进方向 | 逆波动加权、15/45 日区间混合 |

**一句话理解**：这就是「收盘价在 15 日区间里的相对位置」按周频做横截面多空 ——
和我们做过的 [区间相对位置因子](../../../因子研究/区间相对位置因子/文档/研究计划.md)
几乎同源，也和 [横截面动量](../../横截面动量/) 同一套组合方法。

## 2. 与我们已做研究的差异（这是本轮要检验的核心）

| 维度 | AlphaPilot | 我们的 RelPos | 影响 |
|---|---|---|---|
| 区间端点 | close 的 min/max | 真实 high/low | 他用收盘价会低估区间宽度、把小币插针洗掉；突破信息更纯粹 |
| 是否含当日 | **含**当前 bar | **不含**（shift 1） | 含当日时，创新高当日因子机械等于 1.0 —— 本质是「突破」而不是「位置」 |
| 窗口 | 90×4h ≈ 15 天 | 7/14/30/60 天日线 | 15 天落在我们 14 与 30 之间 |
| 样本 | 2025-04 → 2026-10 | 全历史 | **他这段正好落在我方 um 7d RelPos 最好的两年（2025 +173%、2026 +50%）** |
| 池子 | "head"（未公开，疑似主流币） | 诚实池（含已下架） | 幸存者偏差 / 池子定义不明 |
| 成本 | 3bp 单边 | 5bp + 2bp 滑点 | 他更乐观 |
| 中性化 | 无 | 无 / logADV+Beta | 需检验是否为规模/Beta 影子 |

我方已有结论（必须对照，不能忘）：
- RelPos 组合收益**主要来自做空崩盘币**，Q1 单腿做多年化 −43% ~ −57%；现货可交易的多头腿是亏的。
- RelPos 原始 IC 中性化后翻号（um 7d：+0.17% → −0.45%），更像规模/Beta 影子。
- 横截面动量同池同频 IC 与年化都强于 RelPos（7d：IC −3.47% vs −0.45%）。

## 3. 本轮复现口径（先写死，不许看了结果再改）

数据：`因子研究/行情数据/` 的 `um/1d`、`spot/1d` 收盘价；4h 数据湖没有，
用**日线 close 的 15 天窗口**近似 90 根 4h close（端点为收盘价，含当日），
另做一版「不含当日」用于拆分「含当日」的贡献。

因子（每市场一份 `out/factor_{market}_1d.parquet`）：

```
rp15d      = (close − min(close,15)) / (max(close,15) − min(close,15))   # 含当日，对齐原文
rp15d_excl = 同式，但窗口为 [t−15, t−1]                                  # 不含当日，对齐我们的 RelPos
```

- `min_periods = 10`（窗口攒 2/3 就有值）
- `(max − min) / close < 0.5%` 置 NaN（稳定币 / 一字板保护，沿用 RelPos 项目）
- 端点用 close 的 min/max，不用 high/low（对齐原文）

组合（回测引擎 `因子研究/回测框架/engine.py`）：

- 市场 um（主）与 spot（可执行性检验）；tf `1d`
- 周频调仓（每周最后一根日线 = 周日收盘出信号，周一开盘建仓），持有 1 周；另跑 4 周看衰减
- 5 分组，long_top + long_short（与原文一致：多高位 20%、空低位 20%，两侧各 50%）
- `top_n = 50`（ADV 前 50，近似 "head" 池）；另跑 `top_n = 20` 做池子敏感性
- 等权；`gross_leverage = 1.0`；`neutralize = None`（对齐原文），另跑 `logadv_beta` 稳健性
- 成本：um `fee_bps = 3`、`slippage_bps = 0`（对齐原文 0.03% 单边）；spot 用默认 10bp+2bp
- 资金费：um 计入；`delist_shock = 0`（与既有研究一致，退市按最后价平仓）
- 全历史 + 原文区间（2025-04-01 → 2026-10-31）分别跑

对照因子（同配置并排）：`relpos_14d`（我们的 high/low 不含当日版）、`mom_7d`、`mom_30d`。

## 4. 事先声明的闸门（五道，全过才叫「可交付」）

1. **复现闸门**：原文区间（2025-04-01 → 2026-10-31）、um、top50、3bp 下，
   周频 Q20 多空年化 ≥ 35%、Sharpe ≥ 1.3（允许因日线近似 4h、池子不同而低于原文 70.5% / 2.08）。
2. **全历史闸门**：数据起点 → 2026-10-31 年化 > 0、Sharpe ≥ 1.0、最大回撤 ≥ −40%；
   且**去掉最好一年**后年化仍 > 0（不许只靠单一年份）。
3. **多头腿闸门**：um `long_only` 年化 > 0、Sharpe ≥ 0.8 —— 证明不是纯靠做空崩盘币。
4. **可执行闸门**：spot `long_only` 扣 10bp+2bp 后年化 > 0（现货可复制）。
5. **独立性闸门**：`logadv_beta` 中性化后 IC 与年化同号且仍为正；
   与 `mom_7d`、`relpos_14d` 的周频截面秩相关均值 < 0.85（否则只是换皮的动量/相对位置）。

任一条不过 → 结论按「不通过」处理，不因为原文 +133% 就网开一面。
