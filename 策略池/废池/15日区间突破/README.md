- 因子：`(close − min(close,15)) / (max(close,15) − min(close,15))`，close 端点、含当日。
- 与 `relpos_14d` 秩相关 0.856；与同定义不含当日的版本 0.953 —— 没有新信息。
- 原文区间（81 周）：年化 **+100.9% / Sharpe 1.71 / 回撤 −31.1%**，比原文还好（+195% vs +133%）。
- 全历史（356 周）：年化 **+42.4% / Sharpe 0.95 / 回撤 −46.0%**，弱于同池同频的
  `relpos_14d`（Sharpe 1.41）和 `mom_7d`（1.04）。
- 腿拆解：多高位 20% 全历史 +15.0%/年但回撤 −97.5%；多低位 20% **−55.2%/年**。
  原文区间的多头腿净 +30.5%，价格腿 **−43.6%**，靠 +76.2%/年资金费撑着。
- 现货多头：全历史 −8.4%/年，原文区间 −46.2%/年 —— 不可执行。
