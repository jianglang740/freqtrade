## 一句话

每天在流动性最好的 50 个币里，按 **7 / 14 / 28 日的波动率调整后动量**打分，
做多最强 20%、做空最弱 20%，两边等权、金额中性，日频重建组合。

它赚的不是「大盘涨跌」，而是「强币与弱币之间的差」—— 原文称之为
*long the steady, short the weak*。

---

## 一、原文规则（可直接照做）

### 1.1 数据与调仓时点

- 用小时线，但**只每天调一次仓**，在 00:00 的那根小时 K 线上执行。
- 「日收盘价」取 **23:00 小时 K 线的收盘价**（即 23:59:59 那一刻），
  所以信号只使用已经走完的 K 线，不看正在交易的那根。
- 每天 00:00 按下面的步骤**整体重建**一次组合。

### 1.2 选池：先过滤，再取前 50

1. 计算每个币过去 **14 天**的日均成交额（美元）。
2. 丢掉日均成交额 **低于 100 万美元**的币。
3. 在剩下的币里，按成交量取**最大的 50 个**。

### 1.3 打分：波动率调整动量

对每个币、每个回看窗口 `N ∈ {7, 14, 28}` 天：

```text
m_N = (P_t / P_{t-N} - 1) / σ_N

P_t  = 日收盘价
σ_N  = 过去 N 个日收益率的标准差
```

直觉：同样是涨 20%，一步一步稳涨的币得分高，一根暴力拉升的币得分低。
原文认为前者的买盘更持续，后者更容易反转。

然后把三个分数分别在这 50 个币里做 **z-score**（减去截面均值、除以截面标准差），
取平均作为最终分数：

```text
Score = [ z(m_7) + z(m_14) + z(m_28) ] / 3
```

### 1.4 组合构建

- 做多 Score 最高的 **20%**（50 个币里就是 10 个）。
- 做空 Score 最低的 **20%**（10 个）。
- 中间 60%（30 个）空仓。
- **每一边的总权重相同**，边内每个币等权。
- 原文用 **2× 杠杆**：平均约 95% 净值做多、94% 做空，净暴露接近 0。
  换算下来每个持仓约 9.5% 净值。

### 1.5 成本

- 每笔按成交额收 **0.03%** 的手续费 + 滑点（开仓、平仓各收一次）。
- 资金费（funding）已计入回测。
- 18 个月共 **4,780 笔**成交。

### 1.6 伪代码

```python
# 每个 00:00 UTC
universe = [c for c in coins if avg_dollar_volume(c, 14) >= 1_000_000]
universe = top_by_volume(universe, 50)

score = {}
for c in universe:
    ms = []
    for N in (7, 14, 28):
        ret = close[c][t] / close[c][t - N] - 1
        vol = std(daily_returns(c)[-N:])
        ms.append(ret / vol)
    score[c] = ms

for N_idx in range(3):
    z = zscore_across(universe, [score[c][N_idx] for c in universe])
    for i, c in enumerate(universe):
        score[c][N_idx] = z[i]

final = {c: mean(score[c]) for c in universe}

longs  = top(final, 10)     # 前 20%
shorts = bottom(final, 10)  # 后 20%
# 两边各 1× 净值（2× 杠杆下），边内等权；次日 00:00 开盘执行
```

## 二、原文的回测结果

### 2.1 总览

| 指标 | 原文数值 |
|---|---|
| 区间 | 2025-04 → 2026-09（18 个月） |
| 起始资金 | $10,000 |
| 总收益 | **+646.71%** |
| 年化 | **+281.57%** |
| Sharpe | **2.61** |
| 最大回撤 | **33.08%** |
| 基准收益 | **−30.1%** |
| 成交笔数 | 4,780 |
| 手续费影响 | −54.7% |
| 资金费影响 | −42.8% |

原文自己给出的换算：$10,000 变成约 $74,700；18 个月里 13 个月为正；
最好的是 2025-07（+63.6%），最差的是 2025-11（−12.6%）。

> 「手续费影响」「资金费影响」的单位原文没有写清（百分点还是占毛收益的比例），
> 但两项加起来接近 100 个百分点，说明**成本是这套策略的主要对手**。

### 2.2 原文对「为什么有效」的解释

1. **动量会延续**：新闻、叙事、注意力在币之间扩散不均，资金流入/撤出往往持续数天到数周。
2. **除以波动率能区分趋势与脉冲**：同样涨幅，稳涨比暴力拉升更可能是持续买盘。
3. **三个窗口互补**：7 天反应快但噪声大，28 天稳定但慢；要求多个时间尺度都强，
   可以过滤一周的偶然行情。
4. **多空对冲掉市场方向**：两边规模接近，大盘暴跌时两边一起亏，相互抵消；
   剩下的是强币与弱币的差。原文称这正是基准跌 30.1% 时它还能赚钱的原因。
5. **流动性过滤保证可交易**：只做最活跃的 50 个，避免回测价格根本成交不到。

### 2.3 原文提出的两个改进

1. **持有缓冲（holding buffer）**：现在排名掉出前 20% 就卖，很多币在 20% 边界反复横跳。
   改成「进入前 20% 才买，跌出前 40% 才卖」，可以大幅降低换手，信号几乎不变。
2. **按波动率倒数配权**：现在边内等权，波动最大的币主导了组合的日波动。
   改成每个币按 `1 / 28 日波动率` 配权，让每个持仓贡献相近的风险，可能压低回撤。

## 三、审阅：哪些可信，哪些要打问号

### 3.1 合理的部分

- **规则完整、可复现**：选池、公式、分位、权重、调仓时点都写清楚了，
  比大多数「只给曲线不给规则」的策略文章强。
- **信号时点没有明显前视**：用 23:00 收盘、在 00:00 执行，等于「收盘出信号、下一根开盘成交」，
  这是正确的做法。
- **市场中性 + 流动性过滤 + 多窗口 + 波动率调整**，每一项都是有文献支持的标准做法，
  不是拍脑袋的形态。
- **成本没有藏着**：明确给了手续费和资金费的拖累，也承认 33% 的回撤和 18 个月的样本限制。
- 两个改进方向（缓冲、逆波动率配权）都是真正能改善执行的点。

### 3.2 需要打问号的地方

1. **18 个月、单一行情。**
   2025-04 → 2026-09 恰好是基准跌 30% 的一段。市场中性策略在「横截面离散度大」的行情里
   最容易好看；换到普涨、相关性高、离散度低的行情，多空价差可能迅速变薄。
   原文没有给出分年度/分行情的结果。

2. **2× 杠杆放大了收益，也放大了尾部风险。**
   杠杆本身不改变 Sharpe（收益和波动同比例放大），但会改变回撤路径、强平概率和资金费。
   从「95% 多头 + 94% 空头」看，2× 指的是**总敞口约 2 倍（每边约 1×）**；
   33% 的回撤是加杠杆之后的数字，原文没有给出无杠杆版本。

3. **幸存者偏差没有交代。**
   标的池是「今天还在交易的币」。退市、归零的币不在池里：
   多头因此避开了归零币（高估收益），空头也因此做空不到后来归零的币（低估收益）。
   在 2025-2026 的大量新币里，这个偏差可能不小。

4. **0.03% 的摩擦假设偏乐观。**
   对 BTC/ETH 永续或许够，但对市值排名 20–50 的 alt 永续，taker 费 + 滑点 + 冲击成本
   通常不止 3 bp。原文没有给交易所、VIP 等级、下单方式（市价/限价）和成交量假设。

5. **换手很高，成本结论对费用假设极其敏感。**
   4,780 笔 / 18 个月 ≈ 每天 8.8 笔；相对于 20 个持仓，这是很高的周转。
   手续费 −54.7%、资金费 −42.8% 已经是很大的拖累；费用翻倍，收益可能腰斩。
   这种策略的生死线是 `cost_R = 单笔成本 / 单笔预期优势`，原文没有给。

6. **三个窗口并不独立。**
   7/14/28 日收益高度重叠，三个 z-score 的相关性很高；「三个时间尺度」的实际分散效果
   远小于字面感觉，更接近于一个平滑的 7–28 日动量。原文把它当成三个独立证据，略有夸大。

7. **「基准 −30.1%」的口径要看清。**
   页面元数据里基准写的是 *Equal-weight pool*（等权币池），不是 BTC。
   多空策略跑赢一个下跌的等权池，并不自动说明它在上涨行情里也能跑赢。

8. **没有参数敏感性、没有走样本外、没有实盘记录。**
   7/14/28、20%、50 个币、$1M 门槛都是很「圆」的默认值，没有调参的痕迹（这是好事），
   但也没有证明这些参数在别的区间不脆弱。文章 2026-10-31 发布，回测到 2026-09，
   没有实盘或 paper trading 记录。

9. **平台激励。**
   AlphaPilot 是策略市场，用户投稿的回测天然有「展示好看」的动机。
   原文末尾也写了「这是一次 18 个月的回测，不是承诺」，这句要当真。

10. **一些没有回答的问题**：
    哪个交易所、永续还是现货、标的池如何定义（是否包含刚上市 28 天内的币）、
    退市怎么处理、资金费按哪个价格算、00:00 成交用开盘价还是收盘价、
    2× 杠杆的保证金/强平怎么模拟、空头借币成本是多少。

### 3.3 一句话判断

**规则本身是一个正经的横截面动量变体，值得放进策略池做验证；
但 +646% / Sharpe 2.61 是「18 个月 + 2× 杠杆 + 乐观成本 + 幸存者偏差」共同作用的结果，
不能当作预期收益。** 真正值得抄的是它的执行纪律（日频、等权、多空对冲、流动性过滤），
以及原文自己提出的缓冲和逆波动率配权。

## 四、和本地数据、已有研究的关系

### 4.1 关键观察：不需要 1 小时数据也能复现信号

原文用小时线，信号取 **23:00 那根 K 线的收盘价**，在 00:00 那根 bar 执行。
在 Binance 的 UTC 口径下，1d K 线收盘时点就是 23:59:59，和 23:00 小时线的收盘是同一时刻
（若原文用的是别的交易所或非 UTC 日线切分，需要重新核对）。
因此对**信号**而言：

- **日线完全够用**：`P_t` = 当天 1d 收盘，次日 1d 开盘执行。
- 流动性过滤也只需要日线的 `收盘价 × 成交量`（本地 volume 是标的币数量，
  乘收盘价可近似美元成交额）。

这大大降低了复现成本 —— 不必先补 50 个币的 1h 数据。

### 4.2 本地数据够不够

按 [K线数据报告.md](../K线数据报告.md)（2026-10-31 生成）：

| 数据 | 现状 | 对复现的意义 |
|---|---|---|
| 现货 | 100 对，仅 `1d`，2017-08 → 2026-08 | 可做长历史信号研究；但现货不能做空 |
| 合约 | 95 对；3 对全周期，其余 92 对均为 `1h+4h+1d` | `1d` 足够算信号；做空必须走合约 |
| mark | 95 对均有 `1h` mark（同时有 `4h/1d`） | 回测计资金费直接可用，框架默认 `mark_ohlcv_timeframe=1h` |
| funding | **95 / 95 对**（2026-10-31 补齐） | 默认口径下都能完整计资金费；EPIC 因退市结算，末次为 2026-10-20 |

结论：

- **信号层**：用合约 95 对的 `1d` 面板即可，样本从 2022-12 起
  （其中 30 对上市较晚、从 2023-01 起）；用现货 100 对可以把历史最早拉到 2017-08，
  但只能研究多空价差，不能直接交易。
- **交易层**：做空只能走合约。95 对现在都有 funding 和 1h mark，资金费不会再被静默按 0；
  唯一例外是 EPIC 在 2026-10-20 之后（`SETTLING`，交易所不再产生资金费）。
- **1h 数据**：如果坚持按原文的 23:00 收盘 + 00:00 成交，`1d` 已等价，不必补；
  现在 1h 也已全量存在，做日内对照可以直接用。

### 4.3 和我们之前做过的横截面动量

我们此前用**现货 100 对日线**做过一版 `L30 / Q20` 的横截面动量多空
（30 日回看、前后 20% 分位、无波动率调整、无杠杆，成本口径很粗），
最好的一组样本约 **+110%、最大回撤约 78%**。

和本篇的区别：

| 维度 | 我们之前的 L30/Q20 | 本篇 |
|---|---|---|
| 打分 | 单窗口原始收益 | 7/14/28 日、除以波动率、z-score 平均 |
| 样本 | 更长（2017 起） | 18 个月 |
| 杠杆 | 无 | 2× |
| 成本 | 简化 | 手续费 + 资金费，且占比很高 |
| 结论 | 回撤极大，不能直接实盘 | 原文回测很漂亮，但未复现 |

两者不能直接比数字；但之前的经验说明：**这类策略在我们自己的数据上不是稳定印钞机，
回撤可以非常大。** 本篇的波动率调整和多窗口，正是值得在同一个面板上对照检验的变量。

## 五、如果要验证：一个事先定好的最小实验

> 原则：变体事先列清，跑完不按结果增删；净值与毛值分开；手续费与资金费分开；
> 必须和等权池、BTC 买入持有、以及之前的 L30/Q20 对照。

> **已执行（2026-10-31）**：V0–V7 全部跑完，结果、可行性判断和优化方向见
> [风险调整动量多空_验证.md](风险调整动量多空_验证.md)。
> 一句话：1× 净年化 41%、Sharpe 1.49、回撤 −34%，但**币池是事后选的**，这个数字只能当上限；
> 空腿每年白付近 20%，改成「空整池」后波动降三分之一、Sharpe 持平。

### 5.1 数据

- 主面板：合约 `1d`，95 对，2022-12-01 → 2026-10-31
  （其中 30 对从 2023-01-01 起）。
- 长历史副面板：现货 `1d`，100 对，2017-08 → 2026-08（只算多空价差，不做可交易性结论）。
- 资金费：95 对均按文件里的实际结算时点和标记价完整计；EPIC 末次结算为 2026-10-20。
- 流动性：`close × volume` 的 14 日均值 ≥ $1M，再取前 50。

### 5.2 组合

- 每日收盘打分，**次日开盘**调仓（信号整体 shift 一根，杜绝同 bar 成交）。
- 多头前 20%、空头后 20%，两边等权、金额中性。
- 总敞口 1×（每边 0.5×）与 2×（每边 1×）各跑一版。
- 成本：单边 0.03% 基准，另跑 0.06% / 0.12% 敏感性。
- 资金费：按文件里的实际结算时点和标记价计，不用常数。

### 5.3 变体（事先定死）

| 编号 | 改动 | 想回答的问题 |
|---|---|---|
| V0 | 原文规则（7/14/28，Q20，50 币，2×） | 基准复现 |
| V1 | 去掉波动率调整（原始动量） | 波动率调整到底有没有用 |
| V2 | 只用 28 日单窗口 | 三个窗口是否真的互补 |
| V3 | 持有缓冲：进前 20%、出前 40% | 换手能降多少，收益损失多少 |
| V4 | 逆波动率配权（28 日） | 回撤是否变小 |
| V5 | 1× 杠杆 | 去掉杠杆后的真实曲线 |
| V6 | 标的池 30 / 50 / 95 | 容量与分散度的权衡 |
| V7 | 成本 0.03% / 0.06% / 0.12% | 策略对费用的生死线 |

### 5.4 要报的数字

- 毛收益、净收益；手续费、资金费**分开列**。
- 年化、Sharpe、最大回撤、月度胜率。
- 换手率、`cost_R = 单笔成本 / 单笔优势`、手续费占毛利比例。
- 收益集中度：贡献最大的 3 个币/月份占多少。
- 分区间：2022-12 → 2024-12、2025-01 → 2026-09（原文窗口）、2026-10-31 之后。

### 5.5 已知的坑

- **幸存者偏差**：我们的 95 对也是「今天还活着」的币，和原文同病。报告里必须写清。
- **`lookahead-analysis` 会误报横截面策略**：该工具按单 pair 加载数据，看不到全池排序，
  对它跑出来的警报不要盲信；以手工核对 `shift` 和日期对齐为准。
- **资金费缺失是静默的**：没有 funding 文件的币对，回测不会报错，资金费按 0 计。
- **短腿的可交易性**：alt 永续的深度、资金费、强平规则都和 BTC/ETH 不同，
  回测里 0.03% 的摩擦不一定成交得到。

## 六、结论

1. **这是一个规范的横截面动量变体，不是新因子。** 核心是「波动率调整 + 多窗口 + 多空对冲 +
   流动性过滤」，每一项都有依据；真正稀缺的是它把规则写清楚了。
2. **原文的收益数字不能当作预期。** 18 个月、单一行情、2× 杠杆、乐观摩擦、幸存者偏差，
   任何一项都足以让 +646% 缩水；没有实盘记录。
3. **值得先做的不是抄策略，而是用本地日线面板复现 V0–V7。** 如果 V0 在我们的数据上
   连毛收益都不稳定，后面补 1h 数据、补 50 个币的资金费就没有意义。
4. **最值得保留的两个工程细节**：持有缓冲（降换手）和逆波动率配权（降回撤）。
   它们比「把杠杆开到 2×」更能决定这套东西能不能活。
