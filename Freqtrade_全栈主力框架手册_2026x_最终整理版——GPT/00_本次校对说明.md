### 3. 数据库驱动

PostgreSQL 示例按当前官方 advanced setup 文档更新为：

```bash
pip install "psycopg[binary]"
```

以及：

```text
postgresql+psycopg://user:password@host:5432/freqtrade
```

### 4. dry-run 数据库行为

以当前 `configuration.py` 源码为准：在 trade 模式下，dry-run 若没有显式指定其他 `db_url`，会使用 `sqlite:///tradesv3.dryrun.sqlite`；live 默认使用 `sqlite:///tradesv3.sqlite`。需要真正的内存数据库时，可以显式使用 `sqlite://`。
