# 因子数据

从 `因子研究/行情数据/` 数据湖批量算出**因子面板**，供 `因子研究/回测框架/` 直接回测。

这一层只做一件事：**把「过去的数据」变成「当天的因子值」**。
不含任何未来信息，不含任何筛选条件（市值、成交额、上市天数都在回测时按当日截面做），
所以同一个面板可以配不同股票池反复复用，不用为每个池子重算。

---

## 一、目录

```
因子数据/
├── README.md
├── build_factors.py       # 数据湖 → 因子面板（唯一入口）
├── factor_io.py           # 面板读写层（回测框架 import 它）
└── panels/                # 产物，gitignore；删了随时能重建
    ├── spot_1d.parquet    # 现货日线，833,773 行 / 723 个符号 / 15 个因子 / 49 MB
    ├── spot_1d.json       # 元信息（因子清单、行数、日期范围、生成时间）
    ├── um_1d.parquet      # U 本位永续日线，692,415 行 / 921 个符号 / 15 个因子 / 39 MB
    └── um_1d.json
```

**为什么一个 (市场, 频率) 只放一个文件**：回测只读需要的因子列，pyarrow 的列裁剪会把
其余列跳过；为每个因子单开文件反而带来几百个文件的管理成本。

---

## 二、生成

```bash
# 全量（现货日线 / 永续日线）
python 因子研究/因子数据/build_factors.py --market spot --tf 1d
python 因子研究/因子数据/build_factors.py --market um   --tf 1d

# 只算几个因子 / 冒烟
python 因子研究/因子数据/build_factors.py --market spot --tf 1d --factors mom_30d,vol_30d
python 因子研究/因子数据/build_factors.py --market um   --tf 1h --limit 30
```

前提：数据湖已建好（`因子研究/行情数据/` 下有 `spot/1d`、`um/1d`）。
**行情数据更新后必须重跑本脚本**，否则回测用的是旧面板。

## 三、因子清单

命名规则：`<因子>_<窗口><单位>`，日线单位 `d`、小时线单位 `h`。
窗口全部是**尾部窗口**（`rolling` / `shift` 向前看），`min_periods = 窗口的一半`（至少 2），
所以新上市币在窗口攒满一半之后就有值，不会因为一个小缺口整段失效。

### 日线（`--tf 1d`）

| 因子 | 定义 | 读法 |
|---|---|---|
| `mom_7d` `mom_30d` `mom_90d` `mom_180d` | `close_t / close_{t-w} - 1` | 动量：过去涨得多的 |
| `rev_1d` | `-(close_t / close_{t-1} - 1)` | 短期反转，符号已翻正（越大越「刚跌」） |
| `vol_7d` `vol_30d` `vol_90d` `vol_180d` | 日收益滚动标准差 | 波动率；低波异象 / 风险溢价；和动量窗口一一对应，可直接做 `mom_w / vol_w` |
| `skew_30d` | 日收益滚动偏度 | 彩票偏好（右偏的币容易被高估） |
| `maxret_30d` | 30 日内单日最大涨幅 | MAX 效应，和偏度互为验证 |
| `range_30d` | `(high-low)/close` 的滚动均值 | 振幅 / 换手强度 |
| `takerratio_30d` | `taker_buy_quote_volume / quote_volume` 的均值 | 主动买盘占比，买卖压力 |
| `volume_z_30d` | `log(1+quote_volume)` 相对 30 日均值的 z 分数 | 放量倍数，异动 |
| `illiq_30d` | `mean(|ret| / quote_volume × 1e9)` | Amihud 非流动性 |

### 小时线（`--tf 1h`）

窗口换成 bar 数：`24/72/168/720` = 1/3/7/30 天；`vol_24h`、`vol_72h`、`vol_168h`、`vol_720h`。
其余定义与日线一致，只是采样频率更高。

## 四、口径（和股票因子库的对应关系）

| 口径 | 这里的做法 | 为什么 |
|---|---|---|
| 成交额 | 归档官方的 `quote_asset_volume` | 不是 `close × volume` 估算，避开了价格漂移误差 |
| 收益率 | close 的简单收益率 | 币圈复利效应可忽略，简单收益做截面更直观 |
| 极值处理 | **不在面板里做**，回测时逐日截面 MAD 去极值 + Z 分数 | 全样本缩尾会把未来分布信息漏进来 |
| 标准化 | **不在面板里做**，回测时按当日可选池做 | 池子换了，均值/标准差就得换 |
| 复权 | 不做 | 加密货币没有拆股/分红；币本位计价的变化体现在价格里 |
| 停牌/退市 | 不做处理，该日没有 bar 就没有因子值 | 回测层用「当日有没有 bar」判断在不在市 |

> **一句话**：面板里只有**原始因子值**，所有清洗都在回测层按当日截面做。
> 这是唯一没有前视偏差的做法，也是股票框架 `fct_backtest改进版.py` 的做法。

## 五、代码里怎么读

```python
import sys; sys.path.insert(0, "因子研究/因子数据")
from factor_io import load_panel, list_factors, read_meta, available

list_factors("spot", "1d")                      # 15 个因子名
read_meta("um", "1d")["rows"]                   # 692415

f = load_panel("spot", "1d", factors=["mom_30d"],
               start="2021-01-01", end="2025-01-01")   # 左闭右开，UTC
```

返回的是长表 `date / symbol / <因子列>`，`symbol` 是交易所原生写法（`BTCUSDT`），
**不是** `BTC/USDT`；转宽表用 `df.pivot(index="date", columns="symbol", values="mom_30d")`。

## 六、已知限制

1. **只有 USDT 计价**。BUSD/USDC 计价的交易对没进湖，`um` 里的币本位合约也没进。
2. **1h 面板体积大**：全量约 30 倍于日线（3,700 万行量级），首次生成要几分钟。
   回测小时线时务必带 `--start`，否则从 2017 年一路读起会很慢。
3. **没有资金费率类因子**。资金费率在 `因子研究/行情数据/um/funding/`，
   目前只用于回测扣成本，没做成因子——它和永续特有，和「选币」的关系等验证过再加。
4. **因子值可能带 inf**：`build_factors.py` 已经把 `±inf` 转成 `NaN`，
   但仍然会有「窗口不足一半」的 `NaN`，回测层按截面剔除，不做前向填充
   （填了就等于用过去的数据假装今天有观测）。
