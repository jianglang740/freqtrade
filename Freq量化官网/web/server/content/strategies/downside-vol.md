这是一套横截面的「风险偏好」策略：不预测大盘涨跌，只在一个固定的 18 个主流币池里比较谁跌得温和、谁跌得凶猛，做多温和的一侧、做空凶猛的一侧，两腿规模合计固定为净值的 100%。下文把因子定义、选币规则、加权方式和真实回测结果写清楚。

![下行波动率策略决策流程](/api/content/assets/4d1845650cfe2c5b.png)

## 一、策略赚的是什么钱

平时算波动率，上涨和下跌被混在一起平均。但市场对两者的定价并不对称：投资者厌恶下跌，对「跌起来有多惨」的敏感度远高于「涨得多快」。把下跌单独拎出来度量，就得到一个更接近真实风险感受的指标。

这套策略的前提是：**下跌的剧烈程度会持续。** 一个币过去一个月里每次下跌都凶悍，往往意味着持有者结构脆弱、流动性薄、卖压集中，下一次下跌大概率还是这样；反过来，那些阴跌但从不暴跌的币，往往有更厚的买盘承接。做多后者、做空前者，赚的是「风险被误定价」的那部分价差。

它不是 beta。同期同样的 18 个币等权买入持有，收益约等于零（每日再平衡也只是 −13%，最大回撤 −79%）；策略的超额收益来自两腿的选币，而不是这几个币本身涨了。

## 二、因子：下行波动率

对池内每个币，取过去 30 个交易日的日收益率 r：

```
σ⁻ = std_30( min(r, 0) )      下行波动率：只统计下跌日
σ  = std_30( r )              全波动率：用于腿内加权
```

同样一段行情，如果涨幅和跌幅各占一半、幅度相同，σ⁻ 只有 σ 的一半左右——因为上涨日被整体置零。所以要判断「谁更脆」，看 σ⁻ 就够了；真正做加权时再用 σ。

策略还叠加了一个成本过滤：

```
fund7 = 过去 7 天日度资金费之和的均值
```

资金费是做空和小币永久持仓的主要隐性成本。多头方向只在「σ⁻ 最低的 6 个」里挑 `fund7` 最低的 4 个——如果两个币一样稳，优先选持有成本低的那个。

## 三、选币规则

每周一收盘计算、周二开盘成交：

- **多头**：σ⁻ 最低的 6 个候选里，取过去 7 天资金费最低的 4 个；
- **空头**：σ⁻ 最高的 4 个，不做资金费过滤（空头是收资金费的一方，成本方向相反）。

池子是固定的 18 个：AAVE、ADA、APT、ARB、AVAX、BNB、BTC、DOGE、DOT、ETH、LINK、LTC、NEAR、OP、SOL、SUI、UNI、XRP。不随日期变动，所以不存在「币池是事后画出来的」问题，但代价是池子里包含了一批后来跌掉 90% 的币——这正是空头腿的利润来源，也是这个策略有幸存者偏差之外的另一面：它必须做空这些币才能赚到钱。

## 四、权重：两条腿波动率平价

不是每腿各 50%。先算每条腿的组合波动率：

```
σ_L = 4 / Σ(1/σ_i)      多头腿（4 个币，按 1/σ 逆波动加权后的调和平均）
σ_S = 4 / Σ(1/σ_i)      空头腿
G_L = σ_S / (σ_L + σ_S)
G_S = σ_L / (σ_L + σ_S)
```

两条腿的目标是「贡献相同的波动」，所以波动更小的那条腿拿到更大的权重。两腿毛敞口合计恒为净值 100%，杠杆不参与放大：回测里使用 2× 杠杆只是为了让保证金占用降到 50%，在换仓时有现金可用，名义敞口严格等于权重。

每周必须把仓位拉回目标名义额，不能让它自己漂。原因是这个策略每期都会有 1–2 个币换手，不调权的话，赢家会越滚越大、输家越缩越小，半年后就变成了另一个策略。

## 六、偏差、容量与已知失效

- **收益在衰减**：2024 年 +101%，2025 年 +43%，2026 年前九个月只有 +5%。大币的下行波动结构正在被更多人定价，这个因子的溢价在收窄。不要拿 2024 年的数字当预期。
- **必须做空**：空头腿贡献了三分之一以上的收益，而做空的可持续性取决于交易所的借币规则、资金费和小币深度。回测默认这些成本是「免费且充足」的。
- **固定 18 币池**：好处是没有事后选池的嫌疑；坏处是池子本身会老化——今天的主流币，两年前可能还没上市，三年后可能已经不在前列。这是需要定期审视的假设，不是一劳永逸的设定。
- **周度再平衡是收益的一部分**：只在换手时调权，收益会明显下降；完全不调权，策略会退化成「买了不动」，超额收益大部分消失。
- **成本**：3bp 手续费、真实资金费已经计入。实盘的滑点取决于规模：18 个币都是大市值永续，$10M 以内的换手冲击很小。
- **杠杆**：2× 只用于降低保证金占用，不改变名义敞口。实盘如果使用更高杠杆，风险会成倍放大，回测数字随之失效。
