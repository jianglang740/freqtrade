趋势跟踪的难点从来不是「怎么判断趋势」，而是「怎么不在震荡里被反复磨损」。这套策略用两条均线给出方向，再用效率比做一道闸门：只有行情走得足够直的时候才允许开新仓，方向一转就反手，方向不明就空仓。下文把信号、过滤、仓位和真实回测结果写清楚。

![震荡过滤趋势跟踪策略决策流程](/api/content/assets/41d2fade2a270c81.png)

## 一、策略赚的是什么钱

趋势跟踪赚的是「少数几段大行情」的钱。绝大多数时候它在小亏小赚和空仓之间徘徊，把利润集中押在少数几段方向明确的大波段上——所以它的胜率天然不高，靠的是盈亏比。

代价也很清楚：当市场进入反复假突破的状态，策略会连续止损，回撤是「钝刀子割肉」式的。这不是参数没调好的问题，是这类策略的固有形态。

## 二、信号：双均线 + 效率比

以日线收盘计算：

```
MA14、MA40
ER30 = |P_t − P_{t−30}| / Σ|P_i − P_{i−1}|     （i 取过去 30 根）

方向    MA14 > MA40 且 close > MA40  → 多
        MA14 < MA40 且 close < MA40  → 空
        其余                          → 中性
```

均线决定「允许做哪个方向」，效率比决定「现在允不允许开新仓」：

- 方向翻转且 **ER30 ≥ 0.12**：开仓或直接反手；
- 方向翻转但 ER30 < 0.12：不开新仓，已有反向仓位平掉；
- 方向回到中性、且收盘价重新穿越 MA40：平仓；
- 方向与持仓一致：继续持有，不动仓位。

ER30 ≥ 0.12 是这套策略最关键的参数。它要求过去 30 天的净位移至少占全部路程的 12%——换算过来就是「每走 8 块钱，至少有 1 块是朝着目标方向」。低于这条线，均线给出的方向多半来自震荡而不是趋势。

## 三、仓位：波动率目标，入场即定格

```
w = ±(1/3) × min(1, 3.5% / σ20)
σ20 = 过去 20 个日收益的标准差
```

1/3 是三个币的等分上限，两两不相关的话，三个币合计毛敞口不超过净值 100%。括号内是波动率目标：日波动 3.5% 对应满配，波动越大仓位按比例缩小。

和很多波动率策略不同，这里的仓位**只在入场那一刻计算一次**，持仓期间不再调整。趋势走远、波动上升都不加仓也不减仓。好处是不会在趋势中段被一次正常回撤洗出去，坏处是行情极端时仓位不会主动收缩——收益和风险都被「定格」了。

## 四、执行

- 日线收盘后计算信号，下一根 K 线开盘成交；
- 反手（多转空）用同一根 K 线完成：先平掉原仓位，再按新方向的权重开仓；
- 单币只有一个 −99% 的价格兜底止损，用来应对极端行情，正常情况下不会触发——出场完全由信号状态机决定。

## 六、偏差、容量与已知失效

- **样本很短**：114 笔交易、3.4 年，只有一次完整的牛市（2024–2025）。这个样本量不足以证明「策略有效」，只能说明「逻辑自洽、回测没有崩」。
- **胜率 38.6%**：绝大多数交易是小的亏损或打平，全部利润来自少数几次大行情。实盘中连续 5–6 笔止损是完全正常的，心理门槛比数字门槛高。
- **资金费是最大成本**：多头在牛市付资金费、空头在熊市付资金费，四年下来是一笔持续的开销。回测按真实资金费计算，但它会随市场情绪大幅波动，实盘可能更贵。
- **震荡年份会亏**：策略的核心假设是「市场会给出方向」。如果某个年份是宽幅震荡，这套策略会反复开仓、反复止损，回撤会明显大于 20%。
- **三币集中**：BTC / ETH / SOL 都是深度最好的合约，容量不是问题；但三个币的高相关性意味着分散化有限，它们同时进入震荡时，策略会同时空仓，收益也随之消失。
- **仓位不缩放**：持仓期间不做任何调整，意味着一次持续 3 个月的上涨会让仓位占比自然变小（因为其他仓位没动），复利效应弱于每日调仓的策略。
