这是一套市场中性、日频调仓的横截面动量策略：不判断大盘方向，只在同一时点上比较几十个币谁更强、谁更弱，多强空弱，赚两者之间的价差。下面把收益来源、因子定义、币池规则和回测口径逐条写清楚，包括不好看的部分。

## 一、它赚的是什么钱

加密市场的资金在币种之间轮动。新闻、叙事、注意力在币之间的扩散不均匀，买盘和卖盘往往持续数天到数周，而不是同时发生——这就是横截面动量的前提：同一时点，不同币的强弱存在可预测的差异。

策略同时持有多头和空头两条腿，规模相近、方向相反，净暴露接近 0。大盘普涨时多腿赚钱、空腿亏钱，普跌时反过来，市场方向被大部分对冲掉；剩下的账面收益来自「强的比弱的强多少」，而不是「涨不涨」。

代价同样清楚：当所有币同涨同跌、强弱价差收敛时，两条腿会一起不赚钱。这套策略不提供「任何行情都赚钱」的能力。

## 二、因子：波动率调整动量

对池内每个币、每个回看窗口 N ∈ {7, 14, 28} 天，先算这段时间的累计收益，再除以同一窗口内日收益率的标准差：

```
m_N = (P_t / P_{t−N} − 1) / σ_N

P_t  = 当根日线的收盘价（UTC 00:00 收线，信号只用已走完的 K 线）
σ_N  = 过去 N 个日收益率的标准差

Score = ( m_7 + m_14 + m_28 ) / 3

z = ( Score − 池内均值 ) / 池内标准差
    这一步只是把分数摆到可比的尺度上，不改变池内排名
```

除以波动率是这个因子最关键的一步。同样是涨 20%，一步一步稳涨的币得分高，一根暴力拉升的币得分低——前者的买盘更持续，后者更容易反转。所谓「风险调整」，就是把涨幅换算成「每单位波动换来的收益」。

三个窗口互补：7 日灵敏但噪声大，28 日稳定但反应慢。要求三个尺度同时靠前，等于过滤掉「只有某一周偶然很强」的币。z-score 在当天币池内部做，分数只表达相对同池其他币的强弱，绝对值没有意义。

信号只使用 t 时点及之前的数据。前视自查不用 freqtrade 的 lookahead-analysis（它按单个 pair 加载数据，看不到其他币的排名，对横截面策略必然误报），改用区间截断法：把回测截到 2024-06 重跑，与长区间重叠的 1091 笔已平仓交易逐笔完全一致，净利润差 0.000000 USDT。

## 三、币池：每天重新筛一遍

池子不是一份固定名单，每个交易日按下面四条规则重新计算，顺序不能乱：

- 过去 14 天日均成交额（ADV，USDT）≥ $1,000,000，作为流动性门槛；
- 剔除稳定币与法币对（USDC/USDT、EUR/USDT 这类），并要求 28 日年化波动率 ≥ 15%；
- 剩下的按 ADV 从大到小取前 50 个；
- 上市不满所需历史长度的币自动落在池外，不做人工补齐。

真正卡住池子的是第 3 条，不是 $1M 这条门槛。$1M 的门槛 2021 年以后一天都没有生效过：2026 年有两百多个币的 ADV 高于 $1M，而第 50 名的 ADV 已经到了 $9.6M——池子的地板由「第 50 名」决定。所以想扩池，唯一有效的旋钮是 50 这个数字，而实测放宽到 100，2023 年以后年化转负；放宽到 150，最大回撤 −73%。这两个方向我们都不做。

稳定币那条规则是踩了坑之后补上的。信号是「动量 ÷ 波动率」，稳定币的波动率趋近 0，任何 0.05% 的偏离除以 0.0002 都会变成一个极端分数，于是它们被系统性地排到多空两端。修池之前，USDC/USDT 是全样本被选中次数第一的交易对，9 个稳定币/法币对占了 7.0% 的持仓名额、合计是亏钱的。修池之后，2023 年以后年化从 13.1% 抬到 15.6%，回撤从 −36.4% 收到 −35.2%，没有增加任何复杂度。

ADV 的回看周期固定在 14 天：7 天会追成交额的尖峰，64 天会留住已经死掉的流动性，7 / 14 / 28 / 64 四档的日收益相关性在 0.885–0.906 之间，差别落在噪声里。保持 14 天，理由不是它跑得最好，而是没有证据支持换。

## 四、组合构建与调仓

- 池内按 Score 排序，前 20% 做多（50 个币里 10 个），后 20% 做空，中间 60% 空仓；
- 每条腿内部等权，两条腿总规模相同，组合净暴露接近 0；
- 每日 UTC 00:00 用前一根日线的信号重建组合，排名掉出分位就平仓——这就是调仓本身，不是止损；
- 单币只有一个 −25% 的兜底止损，用来防止极端行情把单条腿拖垮。

仓位由波动率目标控制：k = min(0.20 ÷ 63 日已实现年化波动, 上限)，只使用 t−1 的信息，再乘到每笔仓位上。20% 是波动率目标，不是杠杆目标——市场平静时仓位可以更大，剧烈时自动收缩。研究口径的上限是 2.0×，落地版压到 1.0×。

我们试过、并且放弃的东西：单币止损，日频下越紧越坏，3σ 止损把回撤从 −38.8% 打到 −52.7%；持有缓冲，把年化从 41% 砍到 25.5%，只换来回撤少 1 个百分点；剔除高波动币，优势全部集中在 2025-11 → 2026-09 那一段，2023 年反而是 −7.3%，那是押注行情，不是效应；波动率倒数加权，Sharpe 1.59 最漂亮，但最差单日 −13.2%，这是集中度没设上限的签名。扩池和剔除主流币在上一节已经写过，结论同样是放弃。

全样本 24.3% 主要来自 2018–2021：那几年能进池的币只有几十个，ADV 只有 $5–15M、日波动 10–15%，收益和风险都不是今天的形态。2023 年以后只有 15.6%，所以我们对外承诺 13–16% 的年化、0.6–0.7 的夏普和 −35% 的回撤，而不是 24%。

多空拆解：多腿 2092 笔、单笔均值 +1.23%；空腿 2595 笔、单笔均值 −0.01%。空腿这三年既没赚也没赔——它不是 alpha 来源，而是一份为对冲市场方向支付的费用。这三年标的没怎么跌，对冲成本被多头覆盖了；如果下一个周期是多头普涨，空腿会把利润吃回去。

落地回测比诚实池高，不是因为策略变好了，而是币池换了：95 个「今天还活着」的永续，比含死币的 704 个现货对更优质。这些数字只用来确认策略能跑通、行为符合预期，不是收益预期。

## 六、偏差、容量与已知失效

- 幸存者偏差：落地回测看不见已下架的币，而恰恰是它们构成了空腿最好的收益。用含死币的诚实池量过，这层偏差主要抬高的是风险（最大回撤少算约 20 个百分点），对收益的影响不稳定。
- 容量：按平方根冲击模型，这套策略的有效容量在 $1–5M。$10M 规模上，冲击成本是毛利的 1.7 倍。这不是参数问题，是结构问题，所以我们不接受大资金一次性进入。
- 现货做不了空腿：空腿的可交易性（小币永续的深度、借币、强平）只有真实账户才能验证，回测里是免费给的。
- 已经发生过的失效：2024 年诚实池上全年只有 +0.3%；2025-11-06 → 2026-09-14 有一段 −56% 的净值回撤，多头腿崩溃、空头腿补不上。连续一年以上不赚钱，是这套策略已经出现过的事实，不是风险提示里的假设。

## 七、它不适合谁

- 资金超过 $5M 的：冲击成本会吃掉全部超额收益；
- 受不了 −35% 回撤的：诚实池上真实发生过 −56%；
- 需要每月正收益的：2024 年整整一年在诚实池上没有赚钱；
- 只能做现货的：去掉空腿就是另一个策略，而那个策略没有被验证过。
