这是一套只做 BTC 和 ETH 的短周期动量策略：在 1 小时级别上判断「成交量是否放大、价格是否刚刚创出阶段新高」，信号成立就顺势入场，按波动率倒数决定这一笔用多大仓位，结构被破坏就离场。下文把收益来源、信号条件、仓位规则和真实回测口径逐条写清楚，包括不理想的部分。

![突破动量策略决策流程](/api/content/assets/2c345bd6d38e00fe.png)

## 一、策略赚的是什么钱

价格的突破往往不是一次性完成的。当一段区间被向上突破、同时成交量明显高于过去一周的平均水平，通常说明有新的买盘在持续进场，而不是某一次随机波动。策略赌的就是这种「刚刚启动」的时刻之后还有一段延续。

这套策略的期望值并不高，它的价值在结构上：

- 只做两个最深的池子，滑点与冲击成本可控；
- 单笔仓位按波动率缩放，市场剧烈时自动变小，所以最大回撤只有 10% 量级；
- 持仓周期以小时计，和按天、按周调仓的策略在时间尺度上错开，收益来源重叠很小。

不要把它当成高收益产品。它的定位是组合里的一层低回撤收益流，用来平滑整体的净值曲线。

## 二、信号：突破 + 量能 + 效率比

以 1 小时 K 线为单位，多头需要同时满足以下条件：

```
量能     24 小时均量 > 7 日均量（168 小时）
趋势     MA72 > MA240，且收盘价 > MA240
突破     收盘价 > 前 36 小时最高价（不含当前 K 线）
位置     收盘价 ≥ 0.96 × 过去 240 小时最高价
效率比   ER48 ≥ 0.10
```

ER（效率比）衡量的是这段行情「走得有多直」：

```
ER48 = |P_t − P_{t−48}| / Σ|P_{i} − P_{i−1}|   （i 取过去 48 根）
```

分子是净位移，分母是走过的总路程。一路上上下下的震荡行情 ER 接近 0，即使最终价格没怎么动；单边推进的行情 ER 接近 1。「突破 + 高效率比」组合起来，过滤掉的正是「创了新高但其实是宽幅震荡」的假信号。

空头是上面的镜像。原文里还有一个持仓量（OI）条件，这一项因为数据源限制在回测中没有启用——这是本策略最清楚的已知偏差，写在最后一节。

## 三、仓位：波动率目标

每笔交易的目标权重：

```
w = 0.5 × min(1, 0.6% / σ24)
σ24 = 过去 24 根小时收益的标准差
```

含义是：如果最近一天的价格抖动只有 0.6%，就按半仓（50% 净值）做；抖动越大，仓位按比例缩小，抖动翻倍仓位减半。BTC 与 ETH 两个币合计毛敞口不超过 100%，杠杆固定 1×。

这不是「放大收益」的杠杆，而是让风险预算保持稳定的工具。同样是一笔正确判断，行情剧烈时亏得起、行情安静时敢下手。

## 四、出场

```
多头  收盘价 < 过去 24 根最高价 − 3 × ATR24，或 MA72 下穿 MA240
空头  镜像
```

第二条是趋势结构的止损：中期均线跌破长期均线，说明这轮突破所在的趋势背景已经改变，此时不再等价格止损。出场之后，必须重新满足上面的完整条件才能再次入场——不允许在同一个趋势里反复「止损后立刻追回」。

## 六、偏差、容量与已知失效

- **持仓量条件缺失**：原文要求「未平仓量高于 24 小时前」，本地回测没有可靠的 OI 历史，按原文允许的「无数据则跳过」处理。少了这一层确认，入场的信号质量会比原文差一些，突破的假信号更多。
- **样本只有 1.5 年**：161 笔交易，统计上不够长，不足以证明这是一个稳定的效应。至少要再经历一轮完整的牛熊才有说服力。
- **收益集中**：两个币、同一个市场环境，BTC 一旦进入长期横盘，这套策略会明显退化——它需要「有方向的行情」才能赚钱。
- **容量**：这个策略天然适合小资金。BTC / ETH 永续的深度足以承接数千万美元级别的调仓，容量瓶颈不在这里，而在信号本身的容量——进场越拥挤，突破后的延续越短。
- **同根 K 线的出场与入场冲突**：回测里如果同一根 K 线既触发离场又触发反手，我们抑制了入场信号，避免平仓后立刻反向开仓。这一点与原策略的状态机存在细微差别。
