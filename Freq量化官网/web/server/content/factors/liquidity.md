## 定义

常用计价币成交额（quote volume）衡量。它不仅是一个筛选条件，本身也是因子：成交额骤增往往先于价格突破出现。

## 公式

```text
liq = quote_volume / 流通市值
```

## 怎么用

- 构建可交易股票池，剔除成交额过低的币种
- 估算策略容量，避免冲击成本吞掉超额收益
- 异常放量作为事件型信号的触发器

## 限制与坑

加密交易所存在刷量，原始成交额需要打折看待；跨交易所的价格与成交量差异也需要对齐。
