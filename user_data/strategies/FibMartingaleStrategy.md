# FibMartingaleStrategy — 斐波那契马丁格尔策略说明文档

> 短线双向合约马丁策略，ZigZag 波段识别 + 斐波那契回撤 + DCA 加仓。纯固定止盈/止损。

---

## 一、策略哲学

**核心理念：** ZigZag 找到真波段，在斐波那契回撤位开仓，逆向加仓，达到固定止盈就走。

**当前简化版的核心发现：**

- 复杂的追踪止损逻辑会帮倒忙——盈利时过早锁利润，亏损时过早砍仓位
- 两条线（15% 止盈 + 25% 止损）让 DCA 有空间生效
- 入场即锁定 ZigZag 极值，DCA 档位不随行情漂移

**适用场景：**

- 1 分钟 K 线短线操作
- 偏好震荡市的马丁交易
- 主动提取利润的资金管理（赚钱后定期提走）

**不适用场景：**

- 强单边趋势行情
- 永续运行不提取利润

## 三、信号链路

### 3.1 ZigZag 波段确认

逐 K 线维护潜在高点和潜在低点。从潜在高点回撤 > 2.0% 才确认真波段顶；从潜在低点反弹 > 2.0% 才确认真波段底。未确认的极点不参与斐波那契计算。

**重要：** ZigZag 阈值不宜过小。阈值越低确认越频繁 → fib 线跳动越快 → 信号反而越少（价格来不及走到交叉位线就漂走了）。2.0% 在回测中验证为最优。

### 3.2 入场

- 做多：收盘价从上方跌破 `fib_dn_382`
- 做空：收盘价从下方涨破 `fib_up_382`
- 波段幅度 > ZigZag 阈值才允许入场

### 3.3 DCA 加仓

`confirm_trade_entry` 即刻锁定当前 ZigZag 极值存入 `_pending_locks`，`adjust_trade_position` 首次调用时转移到 `_locked_swings`。后续加仓全部用初始锁定的斐波那契线，不受行情更新影响。

```
做多：fib_dn_500 → +1.5x, fib_dn_618 → +2.5x, fib_dn_786 → +4.0x ...
做空：fib_up_xxx → 镜像
```

每补一档，均价被拉低一次。赢家平均补 4 档后反转，输家补 6.6 档被止损。DCA 在输家上放大亏损是策略的核心代价。

### 3.4 退出

```
1. stoploss -25%        ← 保证金亏损 25%，框架自动
2. minimal_roi 15%      ← 保证金盈利 15%，固定止盈
3. custom_exit 超时      ← 持仓 > 30 天不盈利强制退出
```

没有追踪止损，没有自定义 stoploss。复杂度被验证为负收益。

## 四、最新回测结果（2026/01-2026/08，218 天）

| 指标 | 数值 |
|------|------|
| 交易总数 | 560 |
| 胜率 | 69.5%（389 赢 / 171 输） |
| 总收益 | +73.38%（+$3,669） |
| 峰值净值 | $11,233（+124.7%） |
| CAGR | 152.4% |
| 最大回撤 | 23.04% |
| 盈亏比 | 1.10 |
| 做空盈亏 | +$4,919 |
| 做多盈亏 | -$1,249 |

### 退出结构

| 退出方式 | 笔数 | 平均盈亏 | 总贡献 |
|---------|:--:|------|------|
| ROI 止盈 | 389 | +$101 | +$39,260 |
| stop_loss + trailing | 171 | -$208 | -$35,591 |
| **净合计** | **560** | | **+$3,669** |

### 核心洞察

- **赢家 DCA 4 档 vs 输家 DCA 6.6 档**。补 4 档能回头的赢；补 6.6 档不回头的是输。
- **胜率 70% × 15% 止盈 = 正期望**，DCA 放大的输家是策略的固有成本。
- **做空是主要利润来源**（+$4,919 vs 做多 -$1,249），8 个月大盘跌 31%。
- **策略不适用于永续运行**，峰值 $11,233 时提取利润是关键。

## 六、已知问题与修复

| 问题 | 原因 | 修复 |
|------|------|------|
| 实盘 0 单、回测正常 | ZigZag 用 iloc[0] 初始化，低波动永不开单 | 改用前 240 根 K 线 max/min |
| 追踪止损无意义 | trail_activate 大于 minimal_roi | 直接砍掉 custom_stoploss |
| 极值锁定时机偏晚 | 首次 DCA 时才锁 | confirm_trade_entry 即刻锁 |
