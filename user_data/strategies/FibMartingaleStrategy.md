# FibMartingaleStrategy — 斐波那契马丁格尔策略说明文档

> 短线双向合约马丁策略，ZigZag 波段识别 + 斐波那契回撤 + DCA 加仓。纯固定止盈/止损，无追踪干扰。

---

## 一、策略哲学

**核心理念：** ZigZag 找到真波段，在斐波那契回撤位开仓，逆向加仓，达到固定止盈就走。

**当前简化版的核心发现：**

- 复杂的追踪止损逻辑会帮倒忙——盈利时过早锁利润，亏损时过早砍仓位，对DCA的运用没有达到理想效果
- 两条线（15% 止盈 + 25% 止损）反而让 DCA 有空间生效
- 赢家平均 DCA 4 档后反转，输家平均 DCA 6.6 档后被砍

**适用场景：**

- 1 分钟 K 线短线操作
- 偏好震荡市的马丁交易
- 主动提取利润的资金管理，马丁的优点和缺点都是客观存在的，优点是胜率高，缺点是盈亏比失衡，所以马丁的使用必须要结合人为的主动管理，选择合适的市场情况和合适的标的物进行马丁交易，赚钱后务必定期提取利润，不要让策略一直长跑

**不适用场景：**

- 强单边趋势行情
- 永续运行不提取利润

## 二、当前参数（简化版）

| 参数                     | 值       | 说明                  |

| `timeframe`            | `"1m"` | 1 分钟 K 线           |
| `can_short`            | `True` | 做多+做空             |
| `startup_candle_count` | `250`  | 预热 250 根（4 小时） |

### 2.2 仓位管理

| 参数                              | 值       | 说明               |
| --------------------------------- | -------- | ------------------ |
| `position_adjustment_enable`    | `True` | DCA 马丁加仓       |
| `max_entry_position_adjustment` | `7`    | 首仓 + 最多 7 档   |
| `max_open_trades`               | `14`   | 多空合计 14 个仓位 |

### 2.3 止盈止损（极简，两条线）

| 参数            | 值              | 10 倍杠杆下                       |
| --------------- | --------------- | --------------------------------- |
| `minimal_roi` | `{"0": 0.15}` | 保证金盈利 15%（价格涨 1.5%）止盈 |
| `stoploss`    | `-0.25`       | 保证金亏损 25%（价格跌 2.5%）止损 |

**没有追踪止损，没有自定义止损。** 复杂度被证明是负收益。

| `zigzag_threshold` | `0.020` | 价格反向 2.0% 确认 ZigZag 拐点 |

### 2.5 斐波那契与马丁

## 三、信号链路

### 3.1 ZigZag 波段确认

在 `populate_indicators` 中逐 K 线运行：

- 维护潜在高点/低点
- 从潜在高点回撤 > 2.0% → 确认真波段顶，锁定
- 从潜在低点反弹 > 2.0% → 确认真波段底，锁定
- 暂未确认的极点不参与计算

斐波那契线基于 `zz_high` / `zz_low` 计算。

### 3.2 入场

- 做多：收盘价从上方跌破 `fib_dn_382`
- 做空：收盘价从下方涨破 `fib_up_382`
- 波段幅度 > ZigZag 阈值才允许入场

### 3.3 DCA 加仓

首仓后第一次加仓调用时，锁定当前 ZigZag 极值。后续加仓用锁定值计算斐波那契位，不受 K 线更新影响。

```
做多：fib_dn_500 → +1.5x, fib_dn_618 → +2.5x, fib_dn_786 → +4.0x ...
做空：fib_up_xxx → 镜像加仓
```

### 3.4 退出

```
1. stoploss -25% 硬止损    ← 框架自动检查
2. minimal_roi 15% 止盈    ← 盈利达标立即退出
3. custom_exit 超时          ← 持仓 > 30 天不盈利
```

## 四、最新回测结果（2026/01-2026/08，218 天）

### 4.1 总览

| 指标     | 数值                         |
| -------- | ---------------------------- |
| 交易总数 | 565                          |
| 胜率     | 69.6%（393 赢 / 172 输）     |
| 总收益   | **+46.52%（+$2,326）** |
| 峰值净值 | $9,567（+91.3%）             |
| CAGR     | 90.1%                        |
| 盈亏比   | 1.07                         |
| 最大回撤 | 23.68%                       |
| 做空盈亏 | +$4,546                      |
| 做多盈亏 | -$2,220                      |

### 4.2 退出结构

| 退出方式           |     笔数     | 平均 DCA 档 |     平均盈亏     | 总贡献            |
| ------------------ | :-----------: | :---------: | :--------------: | ----------------- |
| ROI 止盈           |      393      |   4.0 档   | +$90 | +$35,459 |                   |
| stop_loss          |      130      |   6.4 档   | -$160 | -$20,851 |                   |
| trailing_stop_loss |      42      |   7.5 档   | -$292 | -$12,282 |                   |
| **净合计**   | **565** |            |                  | **+$2,326** |

### 4.3 核心洞察

**赢家 DCA 4 档 vs 输家 DCA 6.6 档。**

赢家补了 4 档价格就回头了——DCA 成功拉低均价，反弹到 15% 止盈。输家不回头的，一口气补到 7 档，接近满仓才被 -25% 砍掉。

**胜率 70% × 15% 止盈 = 正期望。** 172 笔输家是代价。DCA 档数差 2.6 档——如果输家能少补 2.6 档再被止损，亏损会大幅减少。

## 七、优化方向

| 方向             | 思路                                                     |
| ---------------- | -------------------------------------------------------- |
| 限制 DCA 档位    | `max_entry_position_adjustment = 4`，不让输家补到 7 档 |
| 提高 ZigZag 阈值 | `zigzag_threshold = 0.03`，只要更大的真波段            |
| 降杠杆           | `leverage_value = 5`，止损空间翻倍                     |
| 不对称止盈       | 做多/做空用不同的 ROI                                    |
