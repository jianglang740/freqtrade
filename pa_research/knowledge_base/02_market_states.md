# 02｜市场状态：趋势、震荡、宽通道与转换

## 1. 市场状态不是单一指标阈值

市场状态是对一段连续价格行为的综合描述。不要只用均线斜率、ADX 或固定涨跌幅定义 Brooks 式趋势。量化时可以用这些数据作为辅助，但核心应当是结构、推进、重叠、回调与突破行为。

建议输出状态：
- `strong_bull_trend`
- `bull_trend`
- `strong_bear_trend`
- `bear_trend`
- `broad_channel`
- `trading_range`
- `breakout_mode`
- `transition`
- `unknown`

第一版可以合并部分类别，但要保留不确定状态。

## 2. 趋势的行为特征

### 多头趋势常见证据
- 高点与低点整体抬高；
- 多头 K 线推进有效，收盘常靠近本根高位；
- 回调幅度有限，或回调后较快恢复上涨；
- 价格较少在相邻 K 线之间深度重叠；
- 空头反击未能持续，难以破坏主要结构；
- 突破后出现向上跟随。

### 空头趋势常见证据
上述逻辑反向适用：低点与高点下移、空头推进有效、反弹失败、结构向下破坏。

### 强趋势与普通趋势
强趋势可能出现连续大实体、少回调、浅回调、连续收盘靠近极值等特征。强趋势中，逆势反转信号往往风险更高；顺势入场可能更有优势，但追价也会带来较差的止损距离和潜在空间。

### 趋势不等于直线运动
趋势可以由推进段与回调段组成。回调并不会自动终止趋势。判断重点是反向运动是否真正破坏了结构和控制权。

## 3. 震荡区间

震荡常见证据：
- 相邻 K 线高度重叠；
- 上下影线较多，收盘方向交替；
- 突破区间边界后缺乏跟随；
- 多空推进都难以持续；
- 价格反复返回此前成交密集区域；
- 区间上沿和下沿相对稳定，但并非绝对水平线。

区间策略的常见逻辑是靠近下沿寻找多头证据、靠近上沿寻找空头证据。区间中部通常风险收益较差，因为价格到两侧边界的空间有限，方向也不清晰。

但若出现强势突破和持续跟随，必须允许区间状态转变为趋势或突破状态，不能继续机械地在边缘反向交易。

## 4. 宽通道（Broad Channel）

宽通道具有趋势方向，但反向波动较大，外观上可能接近震荡。它对晚入场者不友好：趋势仍存在，但深回调和双向波动容易触发止损。

识别时关注：
- 摆动结构是否仍总体朝一个方向；
- 反向运动是否深，但未持续破坏趋势结构；
- 趋势线与通道线是否容纳较大波动；
- 价格是否在更大方向中形成反向小趋势。

量化系统不必一开始精确区分所有通道类型，但要避免把宽通道误认为极强趋势或完全中性的区间。

## 5. 状态转换

常见转换路径：
- 震荡 → 突破 → 新趋势；
- 趋势 → 回调 → 趋势恢复；
- 趋势 → 宽通道 → 震荡；
- 趋势 → 高潮 / 失败突破 → 反转或区间；
- 窄区间 → Breakout Mode → 向任一方向突破。

转换通常不是某一根 K 线瞬间完成的确定事件。系统应使用状态置信度或候选状态，等待后续行为确认。

## 6. Breakout Mode

当价格在窄范围内压缩、上下边界都清晰，但尚未出现有说服力的方向突破时，可以视为突破模式。它不是做多或做空信号，而是表示市场可能正在积累能量，等待突破方向。

交易含义：
- 不要仅因区间收窄就预测方向；
- 记录上下边界；
- 等待有效突破与跟随，或等待失败突破的反向证据；
- 突破前后使用不同的策略逻辑。

## 7. Always In（当前控制方向）

Always In 是对“此刻哪一边更可能控制市场”的概念性判断，不等于永远持仓，也不等于确定预测。

判断可考虑：
- 近期结构方向；
- 最近一次重要突破的方向与跟随；
- 趋势推进与反向运动的相对质量；
- 反向尝试是否失败；
- 价格是否仍处于原趋势的有效结构中。

工程实现可输出 `always_in = long / short / neutral / unknown`，同时输出支持证据。不能只输出方向而不输出置信程度和反向证据。
