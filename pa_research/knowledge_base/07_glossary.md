# 07｜价格行为中英术语表

| 英文 | 中文建议译法 | 核心含义 | 编码注意 |
|---|---|---|---|
| Price Action | 价格行为 | 通过连续价格变化理解市场 | 不等同于 K 线形态库 |
| Bull / Bulls | 多头 | 预期上涨或推动上涨的一方 | 是方向概念，不是实际订单流观测 |
| Bear / Bears | 空头 | 预期下跌或推动下跌的一方 | 同上 |
| Trend | 趋势 | 一段时间内方向性推进占优 | 需结合结构与跟随 |
| Trading Range | 震荡区间 | 双向交易、重叠与突破失败较多 | 不要只按固定宽度判断 |
| Broad Channel | 宽通道 | 有方向但反向摆动较大的趋势结构 | 容易与震荡混淆 |
| Breakout | 突破 | 价格越过重要结构边界 | 要记录边界与确认时点 |
| Follow-through | 跟随 | 信号后沿预期方向继续推进 | 是后续证据，不能提前使用 |
| Failed Breakout | 失败突破 | 突破后未能维持并返回原区域 | 需要状态机与确认规则 |
| Breakout Pullback | 突破回踩 | 突破后回测原边界 | 可能延续，也可能失败 |
| Pullback | 回调 | 趋势中的反向运动 | 不自动等于反转 |
| Reversal | 反转 | 原有方向控制权转向另一方 | 通常需位置、信号、跟随等证据 |
| Signal Bar | 信号 K 线 | 用于定义交易触发的参考 K 线 | 不等于成交 |
| Entry Bar | 入场 K 线 | 触发或发生入场的 K 线 | 要考虑真实执行时点 |
| Trend Bar | 趋势 K 线 | 实体和收盘位置显示较强方向推进 | 不能脱离背景判断 |
| Doji | 十字星 / 小实体 K 线 | 开收盘接近，推进与回撤相对平衡 | 不自动代表反转 |
| Outside Bar | 外包 K 线 | 高低范围同时超越前一根 | 方向取决于收盘与上下文 |
| Inside Bar | 内包 K 线 | 高低范围位于前一根范围内 | 可能压缩，也可能只是停顿 |
| Always In | 当前控制方向 | 当前哪一方更可能占主导 | 不是保证方向，也不是必须持仓 |
| High 1 / H1 | 第一次向上触发 | 常见于多头回调后的第一次向上尝试 | 依赖回调与触发定义 |
| High 2 / H2 | 第二次向上触发 | 多头背景中的第二次向上尝试 | 不能简单数阳线 |
| Low 1 / L1 | 第一次向下触发 | 空头背景中的第一次向下尝试 | 依赖背景 |
| Low 2 / L2 | 第二次向下触发 | 空头背景中的第二次向下尝试 | 不能独立代表高胜率 |
| Second Entry | 二次入场 | 初次尝试后再次出现的交易触发 | 需定义初次尝试与失效 |
| Wedge | 楔形 / 三推结构 | 同方向多次推进的结构 | 主观性较高，需确认 |
| Spike and Channel | 急速推进与通道 | 先强推进、后较缓通道的趋势形态 | 不能机械套用 |
| Climax | 高潮 | 异常强推进或短期过度延伸 | 强势不等于马上反转 |
| Final Flag | 最终旗形 | 趋势末端暂停后可能失败的结构 | 需背景和后续证据 |
| Magnet | 磁吸位 | 价格可能测试的显著水平或区域 | 不是确定目标 |
| Measured Move | 测量走势 | 以先前走势幅度估计潜在目标 | 是估算，不是保证 |
| Trend Line | 趋势线 | 连接摆动点的动态参考线 | 锚点选择会影响结果 |
| Channel Line | 通道线 | 趋势另一侧的参考边界 | 不是精确边界 |
| Trading Range Breakout Mode | 区间突破模式 | 压缩状态下等待方向突破 | 本身不提供方向 |
| Trapped Traders | 被套交易者 | 入场方向失败后可能被迫退出的人群 | 是推理假设，不是直接可观测字段 |
| Scalp | 短线目标交易 | 寻求较短幅度的交易 | 需明确目标和成本 |
| Swing Trade | 波段交易 | 尝试持有更大走势 | 需要更大的空间和持仓规则 |
| Invalidation | 失效条件 | 使原交易假设不再成立的价格行为 | 应在入场前定义 |
