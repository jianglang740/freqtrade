# 14｜Brooks 术语核对（对照官方来源）

- 版本：V1.0
- 定位：`07_glossary.md` 的**外部核对与勘误补充**。07 是本库自编的中英术语表；本篇对照官方来源核对，并专门记录**网络流传中常见的术语走样**
- 主要来源：Brooks Price Action 官方"缩写/术语"页 `https://www.brookspriceaction.com/acronyms.php`，以及 Brooks Trading Course 的公开论坛与博文
- **定义均为转述，不是原文摘录**。符合 `12_sources_and_limits.md` 第 3 节的边界
- 合规声明：本库是原创的中文归纳，不复制书籍或课程的大段文字，不替代原著

## 1. 为什么需要这一篇

`07_glossary.md` 给出的是本库自己的中文定义。但 Brooks 的术语在网络上被大量二次转述，其中相当一部分**改变了原意**——最常见的是把"腿数计数"（leg count）简化成"第几根 K 线"。

如果本库也沿着走样的定义去做量化，就会造出一个**名字是 Brooks 的、对象不是 Brooks 的**因子。这正是 `09_quantification_spec.md` 第 1 节"领域定义 / 操作定义 / 交易假设"三层必须分开的原因。

**本篇的作用**：给出核对后的定义，并明确指出走样发生在哪里。

## 2. 核心术语核对表

| 术语 | 核对后的定义（转述） | 与 `07_glossary.md` 的关系 |
|---|---|---|
| **Always In（AI / AIL / AIS）** | 如果**被迫必须一直持仓**，你应该在哪一边。"Always-in mode" = 你可以确信该站哪边的时刻。是**摆动概念**；适用于趋势，在震荡区间中使用危险。子类：**AIA** = 激进型 always-in 交易者（约每日 10 次反转），**AIC** = 保守型（约每日 2–5 次） | 07 已有 Always In，本篇补充 AIA/AIC 与"震荡中危险"的限定 |
| **H1** | 多头腿中的**一腿**回调 → 牛旗。通常是 Always-In-Long，但也可能出现在熊势中作为强势的次级反转向上 | 07 已有；本篇强调"**一腿**"是定义核心 |
| **H2** | 多头走势中的**两腿**回调；**也**计作从一波抛售中的**第二次反转向上**，即双底的变体。经典的顺势第二次入场做多 | 07 已有；本篇强调"两腿"与"第二次尝试"两重含义 |
| **H3** | 多头走势中的**三腿**回调 → 通常是楔形牛旗或楔形底 | 新增 |
| **H4** | "High 4" 底 / 牛旗；四腿的熊通道，常为连续的高 2 回调 | 新增 |
| **L1 / L2 / L3 / L4** | 熊腿中的镜像：一/二/三/四腿回调。L2 也 = 第二次反转向下 = 双顶变体；L3 通常是楔形熊旗或楔形顶 | 07 已有 L1/L2；本篇补齐 L3/L4 与楔形含义 |
| **A2 / A22** | 趋势中回到 EMA 的**两腿**回调；A22 = 该两腿回调中的**第二次入场** | 新增 |
| **2E / 2S** | Second Entry / Second Signal。第一次尝试失败后的再次买入/卖出 | 07 已有第二入场；本篇给出缩写 |
| **Breakout（BO）** | 对支撑阻力的**收盘价**穿越——先前一根或多根 K 线的高/低点，或 EMA。多头希望一根大阳线收在最高并远离阻力；若接下来是根阴线跟随，则失败突破的几率上升（反之亦然） | 07 已有；本篇强调"**收盘价**穿越"而非影线穿越 |
| **Breakout Pullback（BP）** | 突破后**数根之内**的小回调（大致 1–5 根），作为顺势设置看待；若你预期它会失败，就叫失败突破——**同一个价格行为，两种解读**（来自 Brooks 著作与 TradingView 摘要的表述） | **新增，且重要** |
| **Breakout Test（BT）** | 回到突破点 / 盈亏平衡止损处的测试性回调——可能超出或不足几个 tick，有时在入场后很多根才发生 | 新增 |
| **Failed Breakout（FBO）** | 反转的突破。官方页把 **Trap** 定义为"突然反转的突破，把趋势交易者套住" | 07 已有失败突破；本篇补充 Trap 的官方定义 |
| **Breakout Mode（BOM）** | "突破模式意味着震荡区间。向上或向下成功突破各约 **50%** 机会，然后约一个基于区间高度的测量走势。第一次向上或向下突破会有 **50%** 机会反转。" | **新增，直接给出官方数字** |
| **Measured Move（MM / MMU / MMD）** | 从突破点投射某一腿的幅度（或区间高度）；也包括 "Measuring Gap"（可能导致 MM 的缺口，**只有事后才能确定**）和 "Negative Gap" | **"只有事后才能确定"这一点对量化极关键** |
| **Spike and Channel（SC）** | 一段突破腿（spike）→ 回调 → 通道中至少再 2 腿，常呈楔形 | 07 已有；本篇补充 2 腿下限 |
| **Trading Range（TR）/ TRD / TTR** | 横向价格行为；TRD = 震荡日。**TTR（紧窄震荡区间）** = "限价单市场……下方大概有买盘、上方有卖盘……**对止损单和摆动交易者不利**" | **TTR 的定义对"不交易"判断有用** |
| **Barb Wire（BW）** | 官方页把它列为缩写但未给独立定义；在 Brooks 教学中指特别重叠、影线密集的 K 线簇（紧窄震荡的一种），突破不可靠。（**定义来自其著作/课程，非此页**） | 新增，并**标注来源非官方页** |
| **Final Flag（FF）** | "通常是趋势之后的一个横向形态。突破常常失败并反转。" 另有 **BFF** = Bar Final Flag，**1BFF** = One Bar Final Flag | 07 已有；本篇补充 BFF/1BFF |
| **Climax 相关** | 官方页使用 **Buy Climax / Sell Climax**（"一根或多根大阳/大阴线收在高/低点附近"）、**Exhaustive Buy/Sell Climax**（过快过远地进入阻力/支撑区）、**XS = Climaxes**。高潮反转 = 趋势以高潮结束并反转。**V Top / V Bottom** = 没有前置双顶/双底的高潮强反转 | 07 已有高潮；本篇补充 Exhaustive 与 V 型 |
| **Major Trend Reversal（MTR）** | 被认为可能持续的趋势反转。官方页列子类：双底/双顶 MTR、更高高点 MTR、更高低点 MTR、更低高点 MTR、更低低点 MTR。**通常需要**：跌破趋势线、测试极值、第二次入场 | **新增。三个必要条件的并列对触发定义很重要** |
| **Wedge（W）** | "楔形，或任何类似的东西，比如任何**三推**形态。" **WT/WB** = 楔形顶/底。另有 **MicroWedge**（3–4 根）、**Nested Wedge**（第 3 腿本身是个更小的楔形）、**Parabolic Wedge**。第三推常会越过趋势通道线 | 07 已有楔形；本篇补充"三推"的等价表述与子类型 |
| **Micro Channel（MC）** | 牛微型通道 = **每个低点都在前一根低点或之上**（完全没有回调）；熊微型通道 = 每个高点都在前一根高点或之下。极强但不可持续，通常以更大的回调结束 | **新增，定义完全可编码** |
| **Micro Double Top/Bottom（MDT/MDB）** | 压缩在约 2 根相邻 K 线上的双顶/双底——微型反转形态 | 新增 |
| **Signal bar（BSB / SSB）** | 入场前、构成交易设置的那根 K 线。官方页对**强**信号 K 线的判据：实体 > 2 tick 且收盘接近该 K 线高点（买）/低点（卖）。另标注 "**Bad** Buy/Sell Signal Bar"——其高/低点成为**磁吸位**，交易者会分批建仓、预期价格回测它 | 07 已有信号 K 线；**本篇补充"强信号 K 线"的可测判据** |
| **Entry bar（EB）** | 实际入场的那根 K 线（典型做法是在信号 K 线之外用止损单入场） | 与 07 一致 |
| **Second entry（2E / 2S / 2EB / 2ES）** | 第二次信号尝试；Brooks 视第二次入场为**更高概率** | 与 07 一致（但概率说法的真实性见第 4 节） |
| **Trapped traders** | "被套的多头……将不得不卖出以减少损失，增加价格走低的可能"；被套的空头反之。**2LBLTP / 2LBRTP** = 第二腿牛/熊陷阱（一次快速反转的大突破） | 07 已有；本篇给出官方表述与缩写 |
| **"5 tick trap"（及 9T、13T、17T、21T、41T）** | Brooks 的 tick 取整陷阱：因为止损单入场需要多一个 tick，交易者通常需要 **6** 个 tick 才能净得 **1** 个点。价格经常恰好停在整数点位之前（例如 5 个 tick），套住预期整数位会到达的人；他们离场，有时引发反转 | **新增。机制上是整数关口/止损聚集效应，但具体 tick 数字无数据支持** |
| **18-bar breakout（18BD/18BU/18BOD/18BOU）** | 前 18 根 K 线区间的突破：官方页称 **80%** 机会它**不会**做出当日反向极值，**90%** 机会该区间"很大"；失败突破变体只有 **20%** 机会做出反向极值 | 新增（数字性质见第 4 节） |
| **99BL / 99BR** | 官方页称 **99.5%** 机会当日至少 3 根 K 线会在某时刻交易于均线下方（99BL）/上方（99BR）至少 1 tick | 新增 |
| **Ledge Top / Ledge Bottom** | 4 根以上 K 线组成的紧窄震荡区间，具有相同的高点（顶）/低点（底）；官方页称 **80%** 突破机会 **且 80%** 机会回调回到该 ledge | 新增 |
| **其他值得记录的** | **DP** = 双顶/双底回调；**TCL** = 趋势通道线；**OOD/HOD/LOD** = 开盘/最高/最低价；**1P** = 强趋势中的第一次停顿/回调；**1LU/1LD/2LU/2LD/3LU/3LD** = 第一/二/三腿上/下 | 新增 |

## 3. 术语在网络流传中的七种走样（本篇最重要的部分）

这一节直接服务于 `09_quantification_spec.md` 第 1 节的"领域定义 vs 操作定义"分离要求。**每一条都是量化时容易踩的坑。**

1. **"H2" 被频繁误当作 K 线形态或单纯的"双底"。**
   Brooks 的 H2 是一个**腿数计数（bar-counting）构造**：在**两腿**回调之后**第二次尝试**恢复多头趋势。它**可以**与双底重合，但官方页是按**结构**定义的（数腿，不数 K 线）。
   许多线上 "H2 指标"（LuxAlgo、TradingView 脚本、博文解释）把它简化为"突破前一根高点的第二根 K 线"——**这是一个与 Brooks 腿数计数实质不同的、更宽松的对象**。
   > **对本库的意义**：`05_setups_and_events.md` 第 5 节明确写"不要把 H2 简化成'最近第二根阳线'"。本次核对**证实该警告指向的正是网络上最普遍的走样形式**。

2. **"H1/L1" 被当作通用的"第一次回调"信号引用**，丢掉了 Brooks 的限定：H1/L1 是**一腿**回调，且通常**单独不可交易**——他要的是第二次入场。

3. **"突破回调"被重新包装成一个独立的图表形态**（"BKP"）。而在 Brooks 的框架里，它只是对**同一段价格行为**的顺势解读——空头会把同一段叫作失败突破。**差别在于解读，不在于 K 线。**

4. **"信号 K 线" 常被当作交易触发点**，而在 Brooks 体系里信号 K 线是**设置**，**入场 K 线**（下一根，在信号 K 线之外挂止损单）才是**触发**。
   > 对本库：`03_bars_and_signals.md` 已区分二者；本条确认了二者的**时间差**在量化中必须显式建模（`entry_bar_time = signal_bar_time + 1`）。

5. **"测量走势" 被某些再包装者改成固定斐波那契比率。** Brooks 的 MM 是基于**前一腿**或**区间高度**的腿幅投射，**不是**斐波那契位。
   > 与 `16_academic_evidence.md` 第 11 节第 5 条一致：斐波那契回撤无严格实证支持。

6. **tick 陷阱（5/9/13/17 tick）** 本质上是**整数关口/止损聚集**效应穿上 Brooks 特定语言的外衣；网络上常被当作"神奇价位"重复，**没有统计支持**。
   > 但机制本身有微观结构证据——见 `15_quantification_case_library.md` 第 6 节（Osler 的止损聚集）。

7. **一个反复出现的抱怨**（中文社区亦有）：他的书**结构零散**，同一形态在不同语境下似乎给出**相互矛盾**的读法（例如缺口在一处被读作延续、在另一处被当作反转警告）。这助长了术语走样。
   > **对本库的意义**：这正说明 `12_sources_and_limits.md` 第 4 节"操作定义版本控制"不是官僚程序，而是必需的——**同一个词在不同语境下可能对应不同的操作定义**，必须各自建版本号。

### 4.1 交易者方程（Trader's Equation）

出自其著作第 25 章（"交易数学"）与课程论坛：

```
(成功概率 × 回报) > (失败概率 × 风险)
```

他给出的分档：
- 概率 **≥60%** → 回报约等于风险即可；
- 概率 **约 50%** → 回报须超过风险（他常说约 **2 倍**）；
- 概率 **≤40%** → 回报须 **≥2 倍**风险。

**他明确说明**："40–60% 规则"指的是**一根 K 线向上 vs 向下移动 X 个 tick 的方向概率**（对约 90% 的 K 线成立），**不是**"在你的止损被打掉之前先打到目标"的概率。

> **这一条极其重要**。把方向概率当作目标命中率，是把这个方程用错的最常见方式——而本库的量化路径（`06_trade_logic_and_risk.md`、`13` 的因子设计）恰恰要求的是**目标命中率**，两者不可互换。

### 4.2 Brooks 本人也淡化这些数字

Brooks Trading Course 论坛的一则回应称：精确的百分比不如它们**相对于 50%（均衡）的相对权重**重要——"**75% 和 80% 相对于 50% 并没有显著差异**"。

> 这条自述其实与 `10_failure_modes.md` 第 5 节"过度依赖固定阈值"完全一致。**连 Brooks 自己都不主张把这些数字当作精确阈值。**

## 5. 对 Brooks 方法的公开批评

**结论先行：截至本次调研，没有针对 Brooks 方法的同行评议或经审计的回测，也没有经过核实的实盘记录。** 批评是**方法论上的**（主观性、不可证伪），**不是实证反驳**。

- **无核实业绩记录**（论坛）：反复出现的批评是——没有实时交易记录、没有业绩数据、示例取自事后图表。有观点认为他是"教育者/课程销售者，不是交易者"；也有人认为其方法主观到无法验证，并把其加仓行为类比为"均值回归 + 马丁格尔"；
- **主观性/回测难题**（NexusFi 研究帖）：量化价格行为需要编码大量"上下文要素"；当简单形态被单独检验时通常"表现不足"，而标准的辩护（"你漏掉了上下文"）使该理论**实际上不可证伪**。该帖指出约 **90%** 的研究工作花在**搭建可检验框架**上；
- **平衡的评价**（对《Reading Price Charts Bar by Bar》的评论）：称之为里程碑，具体性突出（数百张带标注的图表），其群体心理模式有持久性；但"高度主观"、不适合初学者、需要数千小时看盘；
- **中间立场**（ForexFactory）：Brooks 是教师/作者而非披露业绩的交易者；方法据称在 SPY/QQQ/E-mini 上"不错"，但在"黄金上不行"；警告 5 分钟图的回撤约为 15/30 分钟的 **10 倍**；
- **中文社区**（知乎/播客）：方法"极难被量化回测"、需 5–10 年掌握、有大量未定义的专有术语、读法有时不一致；
- **对"80% 法则"的批评**：该 80% 是**市场惯性**，**不是固定胜率**；警告不要用它去对抗真正的突破；必须区分"突破**尝试**"与"已确认突破"。

> **与本项目直接相关**：ForexFactory 那条"5 分钟图回撤约为 15/30 分钟的 10 倍"，与本项目实测（`19_cost_data_and_execution.md` 第 2 节：XAU 5m 费/R = 1.38 不可行；`20` 第 4.6 节：XAU 5m 数据稀疏）在方向上一致——**短周期不是更快的赚钱方式，而是更高的成本与噪声。**
