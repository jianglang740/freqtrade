# 08｜AI 价格行为分析协议

## 1. 目的

本协议规定 AI 在解释图表、设计规则或编写代码时，必须遵循的推理顺序。它用于减少术语误用、形态孤立化、确定性预测和未来函数。

## 2. 强制分析顺序

### Step 1：描述可观察事实
先描述价格本身：
- 近期高低点；
- K 线实体、收盘位置与重叠；
- 最近推进段和回调段；
- 已经发生的突破与失败；
- 当前相对于已知结构的位置。

不要在事实之前直接给出方向结论。

### Step 2：判断市场状态
给出一个主状态和备选状态：
- 趋势；
- 震荡；
- 宽通道；
- 突破模式；
- 状态转换；
- 未知。

必须列出支持证据和反向证据。如果证据不足，输出 `unknown`，不要强行分类。

### Step 3：判断当前控制方向
评估多头、空头或平衡哪一方更有优势。至少说明：
- 最近一次有意义的推进方向；
- 反向运动是否获得跟随；
- 关键结构是否被破坏；
- 当前结论的置信程度。

### Step 4：识别位置
说明价格位于：
- 区间上沿、下沿或中部；
- 已知摆动高低点附近；
- 突破点或回踩区域；
- 趋势线 / 通道附近；
- 潜在磁吸位附近。

若无法确认位置，不得虚构关键位。

### Step 5：识别事件或设置
只能在有证据时标注：
- 突破；
- 突破跟随；
- 失败突破；
- 趋势回调；
- 二次入场候选；
- 楔形或双顶 / 双底候选；
- 反转候选。

每个设置都要标记 `candidate`、`confirmed` 或 `invalidated`，并解释原因。

### Step 6：建立多空情景
分别列出：
- Bull case：什么行为会支持上涨；
- Bear case：什么行为会支持下跌；
- 当前较有优势的情景；
- 让当前判断失效的条件。

### Step 7：判断是否存在交易
只有当市场背景、位置、信号、确认、风险空间同时合理时，才考虑入场。否则输出 `NO TRADE` 并说明原因。

### Step 8：输出交易计划
若存在交易候选，给出：
- setup 类型；
- 触发条件；
- 失效条件；
- 止损逻辑；
- 潜在目标或下一个磁吸位；
- 可能的冲突证据；
- 成本与执行风险。

## 3. 标准输出模板

```yaml
market_state:
  primary: "trading_range"
  alternative: "transition"
  evidence:
    - "高低点重叠增加"
    - "两次突破缺乏跟随"
  counter_evidence:
    - "最近一根多头K线收盘靠近高点"

control:
  bias: "neutral"
  confidence: "low"
  evidence: []
  invalidation: []

location:
  zone: "range_middle"
  nearby_levels: []
  room_to_target: "uncertain"

events:
  - type: "breakout"
    status: "candidate"
    confirmed_at: null
    evidence: []

scenarios:
  bull_case: []
  bear_case: []

decision:
  status: "NO_TRADE"
  reason: "位置居中且缺乏跟随"

risk:
  invalidation_level: null
  stop_logic: null
  execution_risks: []
```

此 YAML 是分析输出格式示例，不代表所有字段都可以仅从 OHLCV 精确测得。无法可靠判断的字段应标为 `unknown` 或 `null`。

## 4. AI 生成算法时的必答问题

每提出一条规则，必须回答：
1. 它对应哪个价格行为概念？
2. 该概念需要什么上下文？
3. 输入数据是什么？
4. 输出字段是什么？
5. 事件在什么时候才算确认？
6. 需要多少根未来 K 线才能确认？如果需要，如何避免提前交易？
7. 什么条件会使事件失效？
8. 哪些情况会产生误报？
9. 如何构造单元测试？
10. 该规则如何在图表中复核？

## 5. AI 不得做的事情

- 不得仅凭一个 K 线名称直接产生交易信号。
- 不得把“更可能”写成“必然”。
- 不得把 Always In 当作确定预测或强制持仓指令。
- 不得把高胜率、盈利能力等未经检验的主张当作事实。
- 不得把未来确认的摆动点回填后用于历史交易。
- 不得为了给出答案而把模糊行情强行归类。
- 不得把评分直接称为胜率或概率，除非经过适当校准。
- 不得省略反向证据和失效条件。
