## 四、踩坑记录

| 序号 | 问题                                                 | 原因                                    | 解决                                   |
| :--: | ---------------------------------------------------- | --------------------------------------- | -------------------------------------- |
|  1  | `RequestTimeout`                                   | 国内直连 OKX 不通                       | 走 SOCKS5 代理`ssh -fN quant-proxy`  |
|  2  | `proxies` 格式不生效                               | ccxt 用`socksProxy` 属性名，不是 dict | 改为`"socksProxy": "socks5h://..."`  |
|  3  | 异步模式超时                                         | 缺`aiohttp-socks`                     | `pip install aiohttp-socks`          |
|  4  | WebSocket 连接失败                                   | SOCKS5 不支持 WS                        | `enable_ws: false`，走 REST 轮询     |
|  5  | 订单簿获取失败                                       | 缺`pysocks`                           | `pip install pysocks`                |
|  6  | 限价单不成交                                         | dry_run 模拟限价单有延迟                | 改用`market` 市价单                  |
|  7  | `Market entry orders require price_side = "other"` | 市价单配置约束                          | `entry_pricing.price_side: "other"`  |
|  8  | 端口 8080 占用                                       | 旧进程未杀死                            | `pkill -9 -f freqtrade`              |
|  9  | `range(len(df)) % 2` 不生效                        | 实时模式下依赖 df 长度不稳定            | 改为`df["date"].dt.minute % 2`       |
|  10  | 策略收不到新信号                                     | 日志输出需看后台进程输出                | 重定向到文件`> /tmp/ftrade.log 2>&1` |

## 五、最终有效配置

**网络代理（三个地方都要配）：**

```json
"ccxt_config":    { "socksProxy": "socks5h://127.0.0.1:1080" },
"ccxt_async_config": { "socksProxy": "socks5h://127.0.0.1:1080" },
"enable_ws": false  // WebSocket 不走代理，必须关掉
```

**pip 额外依赖：**

```bash
pip install aiohttp-socks pysocks
```

**启动流程：**

```bash
# 1. 开代理
ssh -fN quant-proxy

# 2. 启动模拟交易
freqtrade trade -c user_data/config/config_okx.json -s MyStrategy

# 3. 打开监控
open http://127.0.0.1:8080
```

## 六、后续建议

1. **密钥安全**：测试中在配置文件写了真实 API Key，建议去 OKX 删除重建一个只读 Key
2. **服务器部署**：搬到东京服务器后删掉所有 `socksProxy` 配置
3. **策略开发**：用 `freqtrade backtesting` 回测验证策略，通过后再 `freqtrade trade` 模拟盘
4. **配置文件管理**：建议 `config_okx.json`（本地带代理）和 `config_okx_server.json`（服务器不带代理）分开维护
